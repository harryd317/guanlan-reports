# 删除 S2 遗产 UI 实施计划

> 设计依据：`docs/superpowers/specs/2026-08-09-remove-s2-legacy-ui-design.md`

## 1. 基线与失败证据

1. 在隔离工作树运行现有前端定向测试。
2. 截取生产股票池页桌面与手机“删除前”证据。
3. 将前端契约改为：S8/人工分区保留，S2 遗产 DOM、文案、空态、倒计时和专用分组全部不存在。
4. 运行定向测试并记录 RED。

## 2. 最小展示层删除

1. 删除 S2 遗产折叠 DOM 及专用 CSS。
2. 让股票池建模在可见列表前排除 `s2_legacy`，仅返回 S8/人工分区。
3. 删除到期倒计时、遗产计数和遗产渲染分支；保留今天页 `s2_legacy` 排除保护。
4. 运行定向测试并记录 GREEN，再扫描全站活跃 UI 残留。

## 3. 回归与零滚动

1. 运行 `test_web.py`、`test_rules.py`、`test_rules_mid.py`、`test_regime.py` 与镜像同步测试。
2. 运行现有全路由零滚动套件。
3. 额外在股票池路由执行 1440×900 与 390×844 的 `scrollHeight/clientHeight` 和 `scrollWidth/clientWidth` 断言。

## 4. 生产等效验收

1. 记录生产 plist 字节哈希和受保护数据库哈希。
2. 用生产 LaunchAgent 克隆配置、生产启动脚本/静态服务方式、独立端口和只读数据库副本启动等效实例。
3. 复验功能、零滚动与桌面/手机截图，确认生产 plist 及生产库未改变。

## 5. 部署、证据与镜像

1. 提交分支并合并 `main`，记录部署前哈希。
2. 重启生产，验证 `ok=true`、零滚动和生产桌面/手机截图，记录部署后哈希。
3. 产出 `docs/验收-删除S2遗产UI-20260809.md` 及 `reports/evidence/remove-s2-legacy-ui-20260809/` 证据。
4. 提交最终报告，推送公开镜像，用全新克隆复核文档、证据和截图，回报源仓与镜像提交哈希。
