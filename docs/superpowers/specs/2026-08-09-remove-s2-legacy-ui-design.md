# 删除 S2 遗产 UI 设计

## 目标

从生产前端完全移除“S2 遗产（到期自动退出）”区块及一切可见残留，不改动 S2 数据、自然过期、服务端任务和存储结构。

## 已批准交互

- 股票池名单页仅保留“S8 观察池”与“人工观察”两个分区。
- S2 遗产数据不进入股票池可见行，也不计入侧边栏股票池数量。
- 删除折叠容器、标题、空态、数量、到期倒计时以及仅为这些元素服务的 CSS/JavaScript。
- 保留今天页对 `s2_legacy` 的排除逻辑，防止遗产股重新出现在待处理或等买点界面。
- 保留服务端 S2 自然过期代码与数据库内容。

## 实现边界

只修改 `static/home.html` 与前端契约测试。不改 API、Python 服务、表结构、迁移或数据。本次是已有元素的删除，用户已冻结目标文案和交互，无需新增视觉原型。

## 验收

- 先写失败测试，证明旧 DOM 和专用分区逻辑仍存在；再做最小删除。
- 全站活跃前端不含 S2 遗产可见文案与专用 DOM。
- 股票池路由在 1440×900 与 390×844 下满足页面级横纵零滚动；现有全路由零滚动套件不回退。
- 全量回归、生产等效环境、生产部署、数据库前后哈希、截图和镜像新鲜克隆复核全部通过。
