# 观澜前端整体重写设计

日期：2026-08-01  
状态：用户已批准方案 A 与旧路由 404 边界  
视觉与交互唯一标准：`~/Downloads/观澜新前端原型-唯一标准.md`

## 1. 目标

用附件原型整体替换现有前端。新前端只包含四个界面：今天、股票池、个股详情、我的。一级导航只包含今天、股票池、我的。个股详情从股票池或等买点列表进入，不占一级入口。

新前端复用现有 API。除现有账户设置接口外，前端不发起写请求。策略、风控、数据管道、记账、通知和数据库结构保持不变。

## 2. 已批准方案

采用单页原型本体：

- `/` 返回新的 `static/home.html`。
- 页面使用 `#today`、`#pool`、`#stock/<code>`、`#me` 管理四个界面。
- 无 hash、未知 hash 和不完整详情 hash 回到 `#today`。
- 详情返回时恢复股票池子页、名单位置和滚动位置。
- `/` 之外的旧静态页面 URL 使用 FastAPI 默认 404，不显示迁移提示。
- 所有 `/api/*` 路由继续运行。

不新增框架、构建链、运行时依赖或聚合 API。

### 3.3 旧文件归档

把旧 `static/` 内容原样移入 `archive/frontend-legacy-20260801/static/`。归档目录保存原文件和 SHA-256 清单。运行时 `static/` 只保留新 `home.html`。

归档文件不进入导航，不由页面路由提供，也不能通过浏览器访问。

## 4. 后端不可变边界

`service.py` 只允许两类改动：

1. 保留 `/` 页面路由并更新它的说明；
2. 删除第 3.2 节列出的旧页面和旧静态资产路由。

所有 `/api/*` 路由装饰器、请求模型、函数签名和函数源码逐字不动。实现前生成 API 源码清单；实现后重新生成并逐项比对 SHA-256。清单覆盖每个以 `/api/` 开头的路由装饰器及其函数源码。

策略、风控、数据、账本、通知和数据库模块不改。部署前后对生产配置、生产数据库、只读副本和 API 源码清单分别核对哈希。

## 5. 页面结构与视觉

附件原型定义颜色、字体、间距、圆角、层级和交互。实现不得引入 Material 3、Apple 风或旧前端组件。核心令牌保持附件原值：

- 奶油底：`#F6F4EF`
- 卡片：`#FFFDFA`
- 正文：`#2B2620`
- 陶土：`#C96A4A`
- 鼠尾草绿：`#5F7F5E`
- 标题：衬线字体栈
- 正文：无衬线字体栈
- 卡片圆角：`16px`

桌面端保留 200px 左侧栏。手机端隐藏侧栏，在顶部显示三个紧凑导航按钮。详情不是第四个导航项；进入详情时股票池导航保持选中。

## 6. 数据装配

前端在一个适配层中读取现有接口。适配层只做格式化、关联和展示型计算，不写库，不改变后端结果。

### 6.1 启动请求

页面启动时并行读取：

| 接口 | 用途 |
| --- | --- |
| `/api/brief` | 日期、开仓门、待处理、持有、等买点、数据新鲜度 |
| `/api/pool` | 股票名称、代码、状态、现价、买点、止损、行业、仓别 |
| `/api/intraday` | 盘中或最新收盘价、涨跌幅、距买点现成字段 |
| `/api/regime/current` | 市况名称、持续天数、沪深300 与 MA60 因子 |
| `/api/s3/summary` | NH250、NL250、净新高、数据日期 |
| `/api/s3/clusters` | 活跃板块集群与真实成员 |
| `/api/trade/overview` | 账户权益、两仓、验证期、投资仓真实状态 |
| `/api/snapshot_dates` | 建仓计划的当周指数跌幅复算日期 |

请求近期快照时只读取当周所需的 `/api/snapshot/{date}`。前端用相邻交易日沪深300收盘价复算单日涨跌，判断本周是否出现单日跌幅超过 2%。

### 6.2 今天

投机线状态卡显示：

- 开仓门：`/api/brief.market_gate.open`
- 市况：`/api/regime/current.regime_cn`
- 市况持续天数：`/api/regime/current.streak`
- 沪深300距60日线：优先使用 `regime.current.factors.ma_dist_pct`；缺失时用 `market_gate.close` 与 `market_gate.ma` 计算
- 等待天数和历史中位数：仅在 `/api/brief.market_gate.wait` 返回时显示

投资线状态卡显示：

- 标的配置：红利低波 ETF `512890`
- 投资仓笔数和金额：`/api/trade/overview.books.investment`
- 已执行批次：投资仓唯一 `position_id` 数，最多计 5 批
- 下一批：按中国时区计算下一个周三
- 默认批次金额：14,000 元
- 加倍条件：当前自然周任一交易日沪深300单日跌幅小于 -2%，当周批次金额为 28,000 元
- 总批次：5

建仓配置写在新前端常量中：周三、5 批、每批 14,000 元、单日跌幅小于 -2% 当周加倍。它只控制展示，不触发买入，不写数据库。

“待处理”读取 `/api/brief.cards`，每项压成单行。保留后端顺序、股票名称、原因和已有动作标签；新前端不执行卡片动作，因此不渲染买卖、复核或违规处置按钮。没有待处理时显示一行诚实空态。

“等买点”使用 `watchlist` 池行与 `/api/brief.waiting` 交集。每行显示名称、现价、距买点、行业或集群和状态。距买点优先使用 `/api/intraday` 的现成字段；缺失时按 `(现价 / 买点 - 1) × 100%` 展示。点击行进入详情。

“广度”显示 NH250、NL250 和净新高，数据来自 `/api/s3/summary`。界面文案使用“NH”“NL”，不显示 S3、研究闸门或策略说明。

### 6.3 股票池

股票池默认打开“名单”。名单完整展示 `/api/pool.pool`，保留接口顺序。列为股票、状态、现价、距买点和板块。

板块列按以下顺序取值：

1. 股票代码命中 `/api/s3/clusters.members` 时，显示真实集群名称和命中数；
2. 未命中集群时，显示池行 `industry`；
3. 两者都缺失时显示 `—`。

“选股逻辑”严格使用附件原型中的两张说明卡。它是固定产品说明，不读取或修改策略参数，不添加运行状态、回测结果或工程入口。

点击名单行进入 `#stock/<code>`。返回按钮恢复“名单”或“选股逻辑”子页；若详情来自今天页，则返回今天页。

### 6.4 个股详情

进入详情时按需读取 `/api/pool/{code}`，并复用已加载的池行、盘中数据、账户权益和集群数据。

详情显示：

- 名称、代码、行业、状态
- 现价与涨跌幅
- 止损、买点、现价价格阶梯
- 距买点
- 计划风险金额：账户权益的 1%，只作展示
- 相对强度：接口有值才显示
- 板块联动：集群匹配结果
- 状态阶段：候选、研究中、等买点、持有、移出
- 一句依据：优先使用 `key_levels.hint`，其次使用池行 `next_hint` 或 `note`，仍缺失时显示“暂无补充依据”

详情不显示画像、复核、日报、AI、回测、K线、事件列表、违规处置或风控说明。

### 6.5 我的

“账户权益”显示 `/api/trade/overview.account_size`。点击金额进入内联输入；Enter 或失焦保存，Escape 取消。

保存只调用现有 `POST /api/account`：

```json
{"account_size": 500000}
```

新前端不调用其他写接口。后端继续执行该接口已有的账户设置与权益峰值重置语义；前端不新增策略、风控或参数治理调用。保存成功后重新读取 `/api/trade/overview`。刷新页面后必须显示保存值。

两仓卡读取 `books.speculative` 与 `books.investment`，显示持仓笔数和金额。投资仓备注显示下一批日期、序号和金额。实盘验证期使用 `stats_current.n`，上限为 20 笔，并按真实值绘制进度。

“我的”不显示回撤、熔断、仓位上限、权益曲线、绩效统计、违规记录、维修间或任何旧页面链接。

## 7. 缺失数据与错误处理

接口失败时保留已成功加载的区块。对应区块显示“暂时取不到”，不填演示数据，不推导业务结论。

数值字段缺失时显示 `—`。现价或买点缺失时不计算距买点。止损、买点或现价不足三个时，价格阶梯保留可用标记，不制造位置。

账户保存期间禁用输入。保存失败时恢复原值并显示接口错误。禁止把失败值写入 `localStorage`。

## 8. 一屏布局

验收视口为桌面 `1440×900` 和手机 `390×844`。所有主页、子页和股票池子页签在普通视口截图中满足：

- `document.documentElement.scrollHeight === document.documentElement.clientHeight`
- `document.documentElement.scrollWidth === document.documentElement.clientWidth`
- 活动页壳 `scrollHeight === clientHeight`
- 活动页壳 `scrollWidth === clientWidth`
- 关键内容不裁切、不重叠、不逐字竖排
- 不使用 full-page 截图掩盖溢出

手机端通过缩小间距、字号和行高保持一屏；不删除真实行。只有设计指定的档案正文区、档案卡名单、股票/连阳/S8 卡片名单可在固定页壳内内部滚动，不得撑大页面。股票池表格改为紧凑五列布局，允许次要文字省略号截断。

### 8.1 全局永久零滚动规则

所有主页、子页和股票池子页签在桌面 `1440×900` 和手机 `390×844` 下均不得出现页面级滚动。验收必须直接断言 document 和活动页壳 `scrollHeight === clientHeight`、`scrollWidth === clientWidth`，且页壳 `overflow-y` 不是 `auto` 或 `scroll`。任一溢出即验收失败。

今后所有“查看更多”类内容一律使用独立 hash 子页承载。主页只保留单行摘要入口，不得增加可展开长列表、内部详情区或页面级滚动。子页可在固定页壳内设置指定内容区滚动，但页面容器仍不得溢出。

今天页不显示全局“数据截至”页脚，数据日跟随对应子页展示。标题区的实时时钟使用固定宽度等宽数字；交易状态仅映射现有市场时钟模块结果，禁止在前端另行判定交易日。

## 10. 生产等效验收与部署

部署前使用生产 LaunchAgent 配置克隆、生产工作目录规则、相同静态文件服务方式和启动脚本，在独立端口启动生产等效实例。三个数据库使用一致性快照和只读连接。

验收保存八张普通视口截图：今天、股票池、详情、我的各一张桌面图和手机图。证据记录视口尺寸、图像像素、DOM 宽高、滚动尺寸、控制台错误和截图 SHA-256。

在只读副本中单独解除写保护，只为账户保存验收创建一次可丢弃副本。该验收不得接触生产数据库。保存、刷新、读回后销毁副本。

部署门槛：

- 自动化测试全部通过；
- 四界面双视口一屏通过；
- 详情进入与返回通过；
- 权益保存刷新保持通过；
- API 源码清单一致；
- 生产 plist 和三个生产数据库哈希一致；

部署后使用 `./restart.sh` 重启生产服务并复验根页面、旧 URL 404、健康接口和数据库哈希。任一门槛失败立即停止部署或按预声明目标回滚。
