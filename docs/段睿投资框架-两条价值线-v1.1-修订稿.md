# 段睿投资框架：两条价值线（v1.1 修订稿）

> 本文整理观澜所有者段睿的投资思想，供本人研究复盘，也供 Codex 理解系统设计哲学。
>
> 性质：思想文档，不是选股公式，不构成投资建议，也不修改景气线 v0.1–v0.5 的任何冻结口径。本文与冻结文本不一致时，执行以冻结文本为准；如需吸收进系统规则，必须另走预声明追加流程。

## 〇、v1.1 修订边界

v1.1 保留“两条价值线”的核心，同时对 v1.0 两处原则作显式修订：

1. v1.0 将“新业务没有拐点”写成所有投资判断的总开关。v1.1 将其限定为**第二条线的计价开关**：没有可验证拐点，第二条线不计价值；第一条线若独立提供足够折价和回报，仍可单独研究。景气线是否准入，继续执行其冻结闸门。
2. v1.0 将“渗透率 5%—30%”写成最好窗口，将 30% 以上写成见顶风险区。v1.1 将其改为**经验观察区间**：5%—30% 用于提示 S 曲线加速，30% 以上触发见顶复核，但都不自动形成买入、卖出或价值结论。

以上修订只改变思想文档的表述，不改变景气线 v0.1–v0.5 的公式、阈值、数据口径和运行规则。

## 一、核心命题

股票的价值来自两条价值线：

1. **第一条线：既有业务价值。** 公司已经证明能够经营的业务，未来可持续自由现金流的折现。
2. **第二条线：未成熟业务期权。** 公司有权继续投入、扩大、延迟或放弃的新业务，按证据阶段和失败概率折算后的价值。

价值之外还有两个外层约束：

- **资本配置与治理约束**决定两条价值线能否真正归属于股东；
- **时机与仓位约束**决定何时承担风险、承担多少风险。

对采用未杠杆现金流口径的普通工商企业，本框架可以写成两步思考式，而不是机械定价公式：

```text
企业价值
≈ 第一条线的正常化 FCFF 现值
+ 各项第二线业务的未杠杆分阶段期权价值
− 尚未进入业务现金流的总部成本现值

股权价值
≈ 企业价值
− 净债务
− 尚未进入现金流的或有负债
```

第一条线和第二条线都使用未杠杆现金流，并按与风险匹配的资本成本折现。总部成本、未来投入和或有负债如果已经进入业务现金流，不能再次扣除。若研究直接采用股东自由现金流（FCFE）或每股现金流，就不得再减一次净债务。

这条式子有两条铁律：

- 已经进入第一条线现金流预测的新业务，不得再以期权名义重复加值；
- 尚未通过证据门槛的新业务，可以跟踪，但不得因故事动听而计入价值。

## 二、第一条线：既有业务的条件价值锚

### 2.1 定义

第一条线回答：

> 不依靠尚未兑现的新故事，公司当前业务在保守、正常化假设下，能为全部资本提供者产生多少现金；扣除净债务和其他负担后，又有多少归属于股东？

它衡量当前业务在完整经营周期内、扣除必要投入后的可持续现金流，不是“当前净利润乘一个倍数”。

### 2.2 为什么不用“地板价”

既有业务只能提供**条件价值锚**，不能提供绝对地板。技术替代、周期反转、高杠杆、错误并购、治理失效和财务失真，都可能使原有现金流迅速消失。

第一条线的可靠性和估值折价取决于：

- 财务披露可信，审计和监管记录没有破坏性疑点；
- 收入、利润与经营现金流能够相互解释；
- 毛利率、市场份额和周转效率没有持续恶化；
- 维持性资本开支和营运资金需求不会吞掉账面利润；
- 债务期限与现金流匹配，不依赖持续借新还旧；
- 管理层没有用第一条线现金流长期补贴失控项目。

这些条件不是简单的全有或全无。某项恶化通常意味着下调现金流、缩短持续期或提高折现率；财务失真、流动性危机等破坏性事件则可能直接推翻价值锚。

### 2.3 计算口径

对普通工商企业，第一条线可从未杠杆自由现金流（FCFF）出发：

```text
正常化 FCFF
= 周期中枢经营利润 ×（1−有效税率）
+ 非现金费用
− 维持性资本开支
− 正常营运资金增量
```

FCFF 应使用与风险匹配的加权平均资本成本折现。银行、保险、券商、REITs、早期生物科技等行业不适用上述简式，应分别使用可分配权益现金流、剩余收益、资产净值或分阶段研发期权等专门模型，并保持净债务和融资成本口径一致。

研究时还要单独检查：

- 一次性收益和一次性损失；
- 周期高点利润；
- 资本化费用；
- 应收、存货和合同负债的质量；
- 少数股东权益、养老金、担保和其他或有负债。

### 2.4 第一条线的证伪条件

买入前必须写下第一条线的证伪条件。至少覆盖：

- 毛利率或净利率跌破什么水平；
- 市场份额连续几个报告期下降；
- 经营现金流连续偏离利润到什么程度；
- 应收或存货增速超过收入多久；
- 投入资本回报率何时低于资本成本；
- 债务到期额何时超过可覆盖现金流；
- 哪类治理、审计或监管事件直接推翻可信度。

第一条线被证伪时，不得用第二条线的远期故事补洞。

## 三、第二条线：未成熟业务的分阶段期权

### 3.1 定义

第二条线回答：

> 公司是否拥有一项真实、可控制、可以继续投入也可以停止的新业务选择权？这项选择权走到了哪个证据阶段？

第二条线不是成功情景的全部现值。各情景必须包含当时仍需发生的经营投入和资本投入；股权融资还要按现有股东保留的持股比例，或直接按完全摊薄每股价值反映稀释。

```text
某项期权的思考价值
≈ Σ（互斥情景概率 × 该情景的未杠杆现金流现值）
− 尚未计入情景现金流的不可撤销承诺
```

融资成本应进入折现率或相应现金流，不能在式外重复扣除。需要增发融资时，应按现有股东稀释后的持股比例或完全摊薄每股口径表达，不能把“稀释”当作一笔模糊金额直接相减。

这仍是研究表达式，不是把主观概率包装成精确数字的许可证。

### 3.2 五道门

一项新业务必须接受五个维度的审查。技术、需求、单位经济和资金路径构成阶段升级的累计门槛；控制权与独占性决定期权质量和溢价，但普通竞争业务即使没有绝对独占，也可以按其可验证现金流估值。

#### 第一门：控制权与独占性

- 公司是否拥有专利、渠道、数据、客户关系、牌照、成本或供应链优势？
- 这个机会是公司专属，还是所有同行都能复制？
- 公司是否有权决定继续、延迟或停止？

没有独占性，也没有停止权的项目，不是高质量期权，更像一项开放式资金承诺。

#### 第二门：产品与技术可行性

供应端证据按以下顺序升级：

```text
立项/PPT → 样机 → 认证 → 小批量 → 稳定量产 → 良率与成本达标
```

立项、参股、合作备忘录和发布会只能形成线索，不能形成价值。

#### 第三门：付费需求

需求端不宜用一条机械排序。研究应交叉验证三类证据：

- **成交与现金证据：**实际交付、收入、回款和真实终端销售；
- **持续性证据：**复购、续费、留存、客户集中度和渗透率变化；
- **前置承诺证据：**不可随意撤销的付费订单、可核验合同负债和预付款。

一次性交付未必强于持续复购，合同负债也必须拆解构成。可退款订金、履约义务和渠道压货都不能机械等同于真实终端需求。意向订单、预约和市场空间预测只能作为辅助线索。

#### 第四门：单位经济

产品卖出去以后，还要回答：

- 单位毛利是否为正；
- 获客成本和售后成本是否可控；
- 回款周期是否稳定；
- 复购是否降低获客成本；
- 放量后价格下降是否快于成本下降。

收入增长而单位经济恶化，只能证明业务变大，不能证明价值增加。

#### 第五门：规模、资金与退出纪律

- 产能扩大后，良率、毛利和现金周转是否改善；
- 公司还要投入多少资本，资金来自第一条线、债务还是增发；
- 第一条线能否承受最坏情景下的投入；
- 管理层是否设置阶段预算、终止日期和退出条件；
- 项目失败时，公司能否停止，而不是继续沉没成本。

真正的期权必须保留放弃权。管理层拒绝止损，会把期权变成负债。

### 3.3 证据分级与计价资格

| 级别 | 状态 | 最低证据 | 研究处理 |
|---|---|---|---|
| L0 | 故事/线索 | 立项、参股、PPT、市场空间 | 不计价值，只记录 |
| L1 | 可观察期权 | 样机、认证、小批量或少量付费订单 | 列入研究观察，不自动形成仓位或信号 |
| L2 | 已验证期权 | 技术可行、付费需求、初步单位经济和可承受资金路径同时成立 | 认定出现可验证拐点，可按情景和概率计入第二条线 |
| L3 | 成长业务 | 收入、毛利、回款和复购持续扩大 | 逐步提高权重，准备转入第一条线 |
| L4 | 成熟现金业务 | 盈利与现金流可重复、无需依靠故事融资 | 转入第一条线，不再重复计算期权 |
| L5 | 失败/衰退/退出 | 任一阶段的竞争力、经济性或需求被证伪 | 降级、归零、退出或计提损失 |

升级和降级都必须由新事实触发，不能由股价涨跌触发。任一阶段都可因证伪直接进入 L5；L5 既包括早期项目失败，也包括成熟业务衰退。

### 3.4 渗透率的正确用法

“渗透率 5%—30%”可以作为产业 S 曲线的观察区间，不能作为普遍定律。

使用渗透率前，必须说明：

- 分母是哪个市场、地区、客户群和价格带；
- 统计口径是否跨期一致；
- 渗透率增长是否伴随复购和增量毛利改善；
- 市场份额增长来自真实终端需求，还是降价、补贴和压货；
- 行业达到 30% 后，网络效应、集中度或新市场扩张是否仍能提高利润。

因此，更可靠的组合指标是：

```text
渗透率斜率
+ 复购/留存
+ 增量毛利
+ 获客成本变化
+ 竞争强度
+ 剩余市场空间
```

超过 30% 只触发见顶风险复核，不自动判定见顶。

### 3.5 第二条线的证伪条件

每项期权在进入 L1 时就要写下证伪条件，并随证据升级补充。历史条件和变更必须保留审计轨迹；条件一旦触发，应按预先约定立即降级、归零或退出，不得删除条件后继续维持原判断。至少覆盖：

- 技术、认证或量产节点延期多久；
- 订单取消、回款延迟或复购下降到什么程度；
- 毛利、获客成本或售后成本何时证明单位经济不成立；
- 资本开支和现金消耗超过什么上限；
- 竞争对手何种进展会消灭独占性；
- 管理层何时必须停止继续投入。

## 四、两条线必须动态迁移

两条线不是永久标签。业务会在不同状态间迁移：

```text
故事/线索
  ↓ 独占性与技术可行性成立
可观察期权
  ↓ 付费需求与单位经济成立
已验证第二条线
  ↓ 收入、利润和现金流可重复
第一条线现金业务
  ↓ 技术替代、周期恶化或治理失效
衰退/退出线

任一阶段
  └─ 证伪成立 → 失败/归零/退出
```

迁移遵守四条规则：

1. 第二条线成熟后必须转入第一条线，停止重复计价。
2. 第二条线可能补充第一条线，也可能主动替代第一条线；不能为了保护旧利润阻止必要转型。
3. 第一条线恶化时必须下调，不得用远期期权维持原估值。
4. 失败项目必须降级或归零；投入时间长、金额大，不构成继续计价的理由。

## 五、研究顺序、估值、技术面与仓位

### 5.1 先核验经营事实，再判断价格

原原则“先定业绩趋势，再评判股价”保留，但要防止机械使用。

- “先”表示研究顺序：先确认经营质量和现金流质量，再讨论价格；
- 它不表示利润上涨就可以买，也不表示估值可以最后才看；
- 周期行业常在利润最高时市盈率最低，表面上的“增长+低估值”可能正是周期顶部；
- 亏损业务也不能只看会计利润，应同时检查单位经济、再投资回报和现金消耗。

更准确的表达是：

> 先确认经营事实与利润质量，再判断当前价格是否提供足够的期望收益。

### 5.2 技术面只解决执行

技术面不创造企业价值，只解决：

- 何时开始观察或承担风险；
- 当前价格是否透支；
- 市场流动性是否放大失败成本；
- 仓位多大；
- 何时因退出信号降低暴露。

行业拐点、市场流动性、历史价格位置和异常交易信号，都不能把 L0 故事升级为 L2 期权。

特别是：

- “距三年低点”是价格位置，不等于估值便宜；
- 市场水位可以改变行动阈值和仓位，不应改变企业内在价值；
- 技术信号与价值证据冲突时，降低或延后仓位，不改写价值事实。

### 5.3 仓位规则高于价值判断

任何分析都会错。仓位负责让错误可承受：

- 第一条线仓位取决于价值锚的可靠性、折价和证伪距离；
- 第二条线仓位取决于证据级别、剩余投入和失败损失；
- 同一公司两条线的风险高度相关时，不得把它们伪装成两份独立分散；
- 触发硬风险限制时，任何估值判断都不得豁免。

## 六、防止重复计算

每次估值必须进行一次“现金流归属检查”。

### 6.1 三类常见重复计算

1. **把协同效应计算两次。** 第一条线已经因生态、品牌或客户黏性获得高利润假设，又把相同生态完整加到第二条线。
2. **把成熟业务继续当期权。** 新业务已形成稳定利润，却同时出现在核心 DCF 和期权估值中。
3. **把成功情景的成本漏掉。** 只加入未来收入，不扣未来资本开支、亏损、融资和稀释。

### 6.2 归属规则

- 一笔未来现金流只能归属于一条线；
- 共享资产带来的协同，要么体现在第一条线利润率，要么体现在第二条线成功概率，不能两边全额计算；
- 第二条线转入第一条线时，应从期权清单删除；
- 无法拆分时，选择更保守的归属，不追求表面精确。

## 七、统一决策规则

1. **事实先于叙事。** 第二条线没有可核验依据，不计期权价值；第一条线必须建立在可信披露上。
2. **利润与现金相互验证。** 利润要与经营现金流、营运资本和资本开支相互解释，增长要说明资金来源。
3. **单位经济先于规模。** 规模扩大不能掩盖每单位亏损。
4. **拐点决定第二条线是否计价。** 新业务未进入可验证拐点，只跟踪，不加值。
5. **两条线分别证伪。** 第一条线不能靠第二条线补洞，第二条线不能靠第一条线无限续命。
6. **价格决定预期收益。** 好公司、好业务和好投资是三个问题。
7. **仓位保证生存。** 风险规则优先于任何价值判断。

其中第 4 条只约束“依靠第二条线获得收益”的判断。若第一条线自身提供足够折价和回报，第二条线没有拐点并不自动否定第一条线价值；是否纳入某条具体研究线，仍按该研究线的冻结规则执行。

## 八、与观澜景气线冻结口径的对应（仅供理解）

| 思想层 | 景气线现有模块 | 解释边界 |
|---|---|---|
| 第一条线：既有业务趋势 | M3 财务拐点、D2 业务纯度 | 反映经营事实的一部分，不等同完整 DCF |
| 第二条线：产业与业务期权 | M2 行业拐点、D1 行业景气度、事件四要素 | 闸门和景气只证明窗口，不自动证明单位经济 |
| 资本配置与治理约束 | D6 风险扣分、人工一票否决 | 负责扣减和阻断，不构成第三条价值线 |
| 时机与赔率 | M1 流动性水位、D3 历史价格位置、M5 退出信号 | 影响准入、退出和仓位，不代表内在价值本身 |
| 风险底线 | 观澜风控硬拦截 | 任何价值判断不得豁免 |
| 证伪与复盘 | 独立观察池、影子账、退出冷却 | 验证判断，不接真实账户 |

理解本表时必须坚持：

- M1 不因乘入工程评分而成为企业价值来源；
- D3 是价格位置，不是独立估值模型；
- M2 是产业时机闸门，不能替代公司级付费需求和单位经济；
- 当前冻结公式、阈值和数据口径不因本文改变。
