# 验收：删除 S2 遗产 UI

日期：2026-08-09

功能分支：`codex/remove-s2-legacy-ui`

实现提交：`425d361`

生产分支：`main`

## 1. 结论

股票池名单页已删除“S2 遗产（到期自动退出）”区块、空态、数量、倒计时和专用渲染代码。全站活跃前端不再显示 S2 遗产标题、入口或说明文案。

本批没有修改 API、Python 服务、数据库表、迁移或业务数据。S2 自然过期任务与服务日志保留；今天页继续排除 `s2_legacy` 待处理和等买点行，防止已退役内容回流界面。

生产已通过标准 `./restart.sh` 重启。健康接口返回 `ok=true`，启动指纹与磁盘指纹一致。

## 2. 删除范围

前端删除如下内容：

- `#pool-legacy`、`#pool-legacy-count`、`#pool-legacy-body` 和折叠区 DOM；
- `.pool-legacy-summary`、`.pool-legacy` 和 `.expiry` 专用样式；
- “S2 遗产（到期自动退出）”与“当前无 S2 遗产”可见文案；
- `legacy` 专用分组、数量和渲染分支；
- `formatExpiryCountdown`、`expireAt` 展示字段及倒计时渲染。

股票池可见模型在建行前排除 `strategy === 's2_legacy'`，仅返回 `s8` 和 `manual` 两组。侧边栏数量也只统计这两组。

全站扫描只剩两类 S2 文本：`scripts/retire_s2.py` 的退役/自然过期标记，以及 `service.py` 的自然过期日志。两者均不是 UI，且属于本次明确保留的数据生命周期。

## 3. TDD 证据

基线测试先证明旧区块、折叠态、遗产分组和倒计时存在。随后将契约改为“S8/人工分区存在，S2 遗产 UI 不存在”，旧实现出现 2 个失败：

1. DOM 仍包含 `#pool-legacy` 和旧文案；
2. `partitionPoolRows` 仍返回 `legacy` 组。

最小删除后，新契约、股票池建模、今天页 S2 排除保护共 3 项全部通过。前端专项套件共 45 项通过。
