## 偏离指令包的地方(逐条)

1. **compute_next_action 加了 trade_date 参数**:纯函数不取系统时间,"即将过期"判断需要当日日期。
2. **"即将过期≤2交易日"实现为自然日≤4**:纯函数无交易日历;覆盖普通周末,春节/国庆前预警会晚(候选过期有池页倒计时兜底),备案。
3. **事件升级 REVIEW 只对 HOLD/WATCH**:EXIT/TRIM/ENTRY_READY 是更高优先级的执行指令,不被事件降级——事件在卡片 events_diff 与 AI 解读区呈现。
4. **AI 改写建议不覆盖机械层指令**:机械层是纪律输出,AI 的 rewrite 建议并排显示(卡片 ai_note),终判在人(红线7精神)。
5. **每票每日至多解读1条事件**(取首条重要事件):成本护栏,指令包未规定上限。
6. **周报的财报/解禁日历与行业仪表盘**:数据源未接入(任务4),先给池内日程(候选过期/研究截止/冷却结束)并在周报注明。
7. **大盘门口径**:日报尾部沿用现有沪深300 vs MA60(日线);v3 中线卡的周线门升级不在任务3事项清单,随任务4。
8. **测试 12→23 用例、interpret_event 的 busy 协议**:对抗审查驱动的加固。
