返回结构建议：

## 五、事项B：AI 引擎改造（DeepSeek 主，智谱 GLM-5.2 备）

### 目标

完全去掉 Claude Code CLI 运行时依赖。系统的三类 AI 调用都走国产 API：

1. 首页 AI 二审员对话：`reviewer.chat()`
2. 立项报告：`reviewer.generate_thesis()`
3. 事件解读：`reviewer.interpret_event()`

### .env 约定

`.env` 只放本机，不进 git，不上前端。读取时保持/修复 600 权限。

```env
AI_ENGINE=deepseek
AI_FALLBACK_ENGINE=zhipu

DEEPSEEK_API_KEY=sk-xxx
DEEPSEEK_MODEL=deepseek-chat
DEEPSEEK_BASE_URL=https://api.deepseek.com

ZHIPU_API_KEY=xxx
ZHIPU_MODEL=glm-5.2
ZHIPU_BASE_URL=https://open.bigmodel.cn/api/paas/v4

AI_TIMEOUT_SEC=120
```

说明：

- `AI_ENGINE` 可取 `deepseek` / `zhipu`。
- `AI_FALLBACK_ENGINE` 可空；不空时主引擎失败后尝试备选。
- 不再要求 `claude` 命令存在。
- 不再要求 `ANTHROPIC_API_KEY`。
- 保留旧 env 键不报错，但不作为默认路径。

### 实现建议

在 `reviewer.py` 中：

1. 删除/废弃默认 `ENGINE = "claude_code"`。
2. 改为运行时读取：

```python
def current_engine():
    return _read_env().get("AI_ENGINE", "deepseek").strip() or "deepseek"
```

3. 新增通用 OpenAI-compatible 调用函数：

```python
def _ask_openai_compatible(provider, prompt, system=None, timeout=None, allow_web=False):
    ...
```

4. DeepSeek endpoint：

```text
{DEEPSEEK_BASE_URL}/chat/completions
```

5. 智谱 endpoint：

```text
{ZHIPU_BASE_URL}/chat/completions
```

6. 请求体：

```json
{
  "model": "...",
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "..."}
  ],
  "temperature": 0.2,
  "stream": false
}
```

7. 不引入新 SDK，优先用 Python 标准库 `urllib.request`，减少依赖。
8. 国内直连：不要依赖 `REVIEWER_PROXY`；不要因为代理缺失失败。
9. 错误返回人话：缺 key、HTTP 非 200、超时、响应 JSON 结构异常。
10. 错误里禁止包含 key。

### 关于 allow_web

当前 DeepSeek/智谱第一版不接 web_search 工具。`allow_web=True` 时：

- 不报错。
- 在 prompt 纪律中明确：只基于系统注入数据和已有事件推理，不编造外部来源。
- 立项报告的 `source` 字段允许写：`系统行情数据` / `事件流` / `业绩预告/快报` / `证据不足`。

必须改 `generate_thesis()` prompt：

旧逻辑里有“检索真实资料后输出”，现在要改成：

```text
只基于系统注入的行情、业绩、事件与已有论点材料输出。没有外部资料时不得编造链接；证据不足就写“证据不足”。
```

### 设置页 AI 状态

`/api/settings` 或新增 `/api/ai/status` 返回：

```python
{
    "engine": "deepseek",
    "fallback_engine": "zhipu",
    "deepseek_key_present": True,
    "zhipu_key_present": False,
    "model": "deepseek-chat",
    "fallback_model": "glm-5.2"
}
```

前端 `settings.html` 显示：

- 当前 AI 引擎：DeepSeek / 智谱。
- 主 key 是否已配置（只显示“已配置/未配置”，不显示 key 内容）。
- 备 key 是否已配置。
- 本月 AI 调用次数仍沿用 `ai_usage`。

### 测试（TDD）

在 `test_web.py` 追加至少 6 个用例：

- `T5B1`：未配置 key 时，`reviewer.chat()` 返回人话错误，不检查本机 `claude` 命令。
- `T5B2`：mock DeepSeek HTTP 响应，`reviewer.chat()` 成功返回文本。
- `T5B3`：mock DeepSeek 失败、智谱成功，fallback 生效。
- `T5B4`：`generate_thesis()` 走国产引擎 mock，能存 thesis，不要求 Anthropic/Claude。
- `T5B5`：`interpret_event()` 走国产引擎 mock，能解析“验证/削弱/无关”。
- `T5B6`：错误信息不包含 API key 原文。
