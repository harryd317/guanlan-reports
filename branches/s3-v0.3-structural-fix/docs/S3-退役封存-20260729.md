## 2. 独立复算

独立复算只读取 v0.3 已封存 SQLite 账本，使用 Python 标准库直接解析
`result_json`，没有导入任何 `s3_backtest` 模块，没有运行策略、生成信号、
扫描参数或写入账本。

复算口径：

1. 以账本锁定参数 `h3-s2-c3-wbase` 读取样本内和唯一一行样本外结果；
2. 按样本内期末权益比例顺接样本外净值；
3. 年化收益按
   `(期末权益 / 期初权益) ^ (365.25 / 自然日数) - 1`；
4. 最大回撤按顺接净值逐日滚动峰值复算；
5. 胜率、盈亏比和期望只取 `still_open=false` 的 2,576 笔闭环交易；
6. 正收益年份逐年使用当年首尾净值计算；
7. S2 期望直接读取同一本封存账本内唯一一行 S2 对照。
