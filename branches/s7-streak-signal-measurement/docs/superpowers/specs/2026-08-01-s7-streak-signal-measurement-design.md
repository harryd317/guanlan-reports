# S7 连阳尾盘信号测量设计

## 目标

S7 只回答一个问题：冻结的连阳尾盘信号在 2015—2025 年历史数据中是否具有正期望赔率。系统测量固定期限收益和五日最大不利幅度，不设计交易规则、卖出点或仓位。

预声明、2026-08-01 数据边界修订和正式动工确认共同构成需求基线。实现不得从测量结果反向修改任何信号、费用或判定阈值。

## 方案选择

采用逐日流式方案：沿 T1 的 2674 个交易日顺序读取行情，只保留最近三根个股 K 线、最近可靠复权价格、五日路径和最多五个交易日内待结算的信号快照。

未采用两种备选方案：

- 全量 Pandas 方案需要一次载入约千万行行情和市值，内存占用高，失败恢复边界差。
- 大型 SQL 窗口方案会产生高额临时磁盘开销，跨三个只读库的窗口语义难以逐行审计。

逐日流式方案限制未来数据进入当前判定，也能复用 S6 已验证的停牌估值和全市场等权基准方法。

## 模块边界

### `s7_measurement/config.py`

保存不可变常量：研究起止日、A/B 市值阈值、2/3 连、末根 1.5%、一字涨停 9.5%、上市 365 日、0.15% 双边费、四个期限、两个市况值和三项判定标准。运行参数不得覆盖这些常量。

### `s7_measurement/db.py`

只允许写入文件名 `S7_research.local.db`。外部库统一以 SQLite URI `mode=ro` 打开，并立即执行 `PRAGMA query_only=ON`。S7 写事务使用 `BEGIN IMMEDIATE`，每个阶段先写 `running` 清单；成功时原子改为 `complete`，失败时清理该阶段派生表并记 `failed`。

### `s7_measurement/sources.py`

负责三项工作：

1. 校验 T1 日历恰为 2674 日且端点为 2015-01-05 和 2025-12-31；
2. 校验 S7 `daily_basic_raw` 的日期、字段、审计批次和覆盖率；
3. 提供获批 `daily_basic` 的可恢复补齐入口，只请求 `ts_code,trade_date,total_mv`，不改变既有成功批次。

测量命令只调用校验，不主动联网。联网补齐必须由独立显式命令触发。

### `s7_measurement/signals.py`

提供无数据库副作用的纯函数：

- `is_bullish(bar) -> bool`
- `streak_flags(last_bars) -> tuple[bool, bool]`
- `is_one_price_limit_up(bar) -> bool`
- `market_cap_groups(total_mv) -> tuple[bool, bool]`
- `resolve_st_status(day, direct_codes, name_intervals, direct_history_start) -> StStatus`
- `evaluate_signal(inputs) -> SignalDecision`

`SignalDecision` 同时返回 2 连、3 连、A 组、B 组标志，以及所有排除原因。3 连不从 2 连中删除，B 组不从 A 组中删除。

### `s7_measurement/measure.py`

逐日读取 `market_daily` 和 `adj_factors`。每日处理顺序固定为：

1. 读取当日 T1 `gate_open`、市值、行情和复权因子；
2. 更新每只股票最近三根日 K 和最近可靠复权价格；
3. 结算此前信号到期的 T+1/2/3/5 收益和五日路径；
4. 用当日及此前数据生成当日信号，不读取下一交易日；
5. 为当日信号保存全市场等权和沪深300的起始值；
6. 批量写入当日信号、排除原因和已到期测量。

最多同时保留五个交易日的待结算状态。停牌时复权收盘保持最近可靠值；当日无最低价时，五日路径不创造新低。上市前、退市日及其后、目标日仍无可靠价格或目标日越出研究区间时，收益记为无效并保存原因。

### `s7_measurement/report.py`

只从 S7 派生表生成 Markdown 和 CSV。报告包含口径、数据审计、信号数量、排除原因、`st_status_missing`、全样本、年度、市况、交叉切片、最大回撤、两个基准、16 单元判定和整体结论。报告不读取生产账本或调用网络。

### `s7_measurement_cli.py`

提供明确的离线阶段命令：

- `init-db`
- `fetch-daily-basic`
- `audit-data`
- `build-signals`
- `measure`
- `report`
- `verify`

每个命令打印机器可读 JSON；命令失败返回非零状态。`build-signals` 必须先通过覆盖门禁，`measure` 必须确认最新信号运行状态为 `complete`，`report` 必须确认最新测量运行状态为 `complete`。

## 数据模型

S7 保留已经补齐的 `daily_basic_raw` 和 `ingest_audit`，新增以下派生表。

### `run_manifest`

记录阶段、状态、源库 SHA-256、配置指纹、开始时间、完成时间、输入和输出计数。配置指纹覆盖全部冻结常量；指纹变化即拒绝复用旧结果。

### `signal_observations`

每个满足原始 2 连价格形态的“信号日 × 股票”一行。字段包括：

- 信号日、代码、`gate_open`
- 2 连和 3 连标志
- A 组和 B 组标志
- OHLC、`pct_chg`、`total_mv`、上市天数
- ST 判定值、来源和缺失原因
- 一字涨停标志
- 复权买入基价
- `included` 和 `exclusion_reasons_json`

没有形成 2 连原始形态的股票日不属于“被排除信号”，只进入每日扫描计数。每日扫描数、形态命中数和各排除原因计数写入 `exclusion_counts`，保证总体分母可审计。

### `signal_cohorts`

每个有效信号按重叠语义展开为 A2、A3、B2、B3。主键为信号日、代码、组别和连数。一个 B3 信号产生四行：A2、A3、B2、B3。

### `benchmark_measurements`

每个“信号日 × 期限”一行，保存目标日、沪深300收益、全市场等权收益、等权有效股票数和状态。全市场等权使用信号日已上市且起止可靠的全部 A 股同期复权收益算术均值。

### `return_measurements`

每个“信号日 × 股票 × 组别 × 连数 × 期限”一行，保存目标日、毛收益、净收益、两个基准、两项毛超额和状态。净收益公式固定为：

```text
gross_return = adjusted_close_target / adjusted_close_signal - 1
net_return = gross_return - 0.0015
```

### `drawdown_measurements`

每个“信号日 × 股票”一行。五日最大不利幅度公式固定为：

```text
max_adverse_excursion = min(0, min(adjusted_low_T1 ... adjusted_low_T5)
                               / adjusted_close_signal - 1)
```

若 T+5 越界则状态为 `out_of_study_range`，不得用不足五日的路径代替。

### `aggregate_statistics`

主维度为组别、连数、期限、年份和市况。年份与市况均支持 `all`，从而同时表达总体、年度、市况及完整交叉切片。每行保存：

- 观察数、有效数和覆盖率
- 毛收益与净收益的算术均值
- 毛收益与净收益的中位数、25% 和 75% 分位数
- 净正收益率
- 沪深300、全市场等权及两项超额均值
- 五日最大不利幅度的中位数、25% 和 75% 分位数

分位数使用 Python `statistics.quantiles(..., method="inclusive")` 对应的线性插值；单样本切片的 25%、中位数和 75% 均等于该样本。测试用手算常量固定边界。

### `qualification_results`

固定写入 16 行。每行保存净期望、净正收益率、11 个年度是否齐全、负净期望年份数、三项布尔结果和单元结论。整体结论仅为 16 行的逻辑或，不增加其他判断。

## 冻结信号决策

信号先要求最近两根日 K 都为阳线，随后执行以下判断：

1. 最近第三根也是阳线时，同时标记 3 连；
2. `pct_chg <= 1.5`；
3. 信号日上市满 365 个自然日且尚未退市；
4. ST 状态明确为非 ST；
5. OHLC 四价相同且 `pct_chg >= 9.5` 时排除；
6. `total_mv >= 5,000,000` 万元时进入 A；达到 `10,000,000` 万元时同时进入 B。

2016 年起，T1 `stock_st` 在某日存在任何代码即证明该日直达历史已覆盖；目标代码无记录时判为非 ST。2016 年前，曾用名区间含 `ST` 时判为 ST；不存在相应区间时返回未知，记录 `st_status_missing` 并排除。报告单列未知数量、年份分布和对样本规模的影响。

## 收益、基准与切片

T+N 指信号日之后第 N 个 T1 全市场交易日。个股买入基价为信号日 `close × adj_factor`，目标价为目标日最近可靠 `close × adj_factor`。沪深300读取 `index_daily` 的 `000300.SH` 同期收盘。两个基准均不扣费用；个股净收益只扣一次双边总费用 0.15%。

净正收益率使用 `net_return > 0`。净期望使用有效净收益的算术均值。分年度负期望也使用同一净收益均值，不用中位数或超额替代。

每个 A2、A3、B2、B3 × 期限单元计算 2015—2025 十一个年度。年度没有有效样本时，年度完整性失败，该单元不能通过。

## 失败与恢复

- 日历不是 2674 日、端点不符、日期重复或 `gate_open` 缺失：立即失败。
- 信号候选超集的市值覆盖率低于 99%：记录覆盖率并停止，不生成信号。
- 源库哈希在一个运行前后变化：运行失败，删除该运行派生数据。
- 任何外部库无法进入只读模式：拒绝运行。
- 最新上游清单不是 `complete`：下游命令拒绝运行。
- 配置指纹变化：不得复用旧信号、收益或报告。
- 单条数据缺失：保存明确状态和原因，不填值、不静默删除。
- 重跑同一阶段：先清除该阶段及下游派生表，再开始新运行；原始 `daily_basic_raw` 和成功采集审计不删除。

## TDD 设计

所有实现遵循红、绿、重构循环。每个测试先说明它能捕获的生产错误，并使用手算常量，不用被测函数生成期望值。

### 数据边界测试

- 写入非 `S7_research.local.db` 必须失败。
- 外部连接执行写语句必须失败。
- 2673 日、重复日期、缺 `gate_open` 和错误端点分别失败。
- 99% 边界包含 99.0000%，低于边界立即停止。
- 补齐只接受三个字段；成功批次幂等，变更响应不得覆盖旧批次。

### 信号测试

- `close == open` 不是阳线；严格大于才是阳线。
- 两根阳线产生 2 连；三根阳线同时产生 2 连和 3 连。
- `pct_chg == 1.5` 通过，略高于 1.5 排除。
- `total_mv == 5,000,000` 只进入 A；`== 10,000,000` 同时进入 A/B。
- 上市第 364 天排除，第 365 天通过；退市日不再有效。
- OHLC 四价相同且 9.5% 排除；四价不等或涨幅不足 9.5% 不按一字涨停排除。
- 2016 年后 ST/非 ST、2016 年前曾用名 ST、2016 年前未知状态分别命中预期分支。
- 未知 ST 必须写 `st_status_missing`，不能变成非 ST。

### 测量测试

- 复权因子变化时收益按 `close × adj_factor` 手算。
- T+1/2/3/5 使用全市场日历，不使用个股第 N 根有报价 K 线。
- 目标日停牌保持最近可靠复权收盘；目标日前从无可靠价格时无效。
- 净收益只减 `0.0015` 一次。
- 沪深300使用同日期指数收盘；全市场等权使用有效股票收益算术均值。
- 五日最大不利幅度使用 T+1 至 T+5 复权最低价，不包含信号日盘中低点。
- T+5 越界的回撤无效，不能用短路径代替。

### 统计与判定测试

- 均值、中位数、25/75 分位数和净正收益率用小样本手算验证。
- 总体、年度、市况及完整交叉切片的观察数必须守恒。
- 四个重叠信号组分别统计，不能互相去重。
- 三项标准必须在同一单元同时成立；跨期限拼接三项不得通过。
- 净期望等于 +0.15%、净正收益率等于 52%、负年份等于 4 年时均通过边界。
- 任一年无有效样本时年度门失败。
- 16 个单元任一通过则整体通过；全部失败则整体归档。

### 失败原子性与报告测试

- 注入中途异常后，运行清单为 `failed`，对应派生表无残留成功数据。
- 源哈希运行中变化时停止，并保留原始采集表。
- 报告必须出现 `st_status_missing` 数量、99% 覆盖证据、16 单元表和唯一整体结论。
- 报告不得出现交易、仓位、资金曲线、影子启用或生产接入结果。
