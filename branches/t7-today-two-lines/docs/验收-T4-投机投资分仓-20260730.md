## 功能验收

- [x] T4 生效后的系统卡片、交易台直录和 OCR 买入均要求选择投机仓或投资仓；缺失或非法标签由服务端拒绝。
- [x] 仓别在建仓时写入，界面无改标入口，数据库触发器拒绝直接改标。
- [x] 投机仓、投资仓分别展示持仓数、持仓金额、已实现盈亏、胜率和已实现回撤。
- [x] 旧账不追溯，未打标签的既有手工仓明确显示“旧账未归类”。
- [x] 投机仓沿用现有规则；投资仓以 `manual` 记账，不进入 S2 管理，并固定显示“投资线规则未上线，仅记账”。
- [x] 账户总仓位、行业敞口和既有风险键继续按全账户计算，没有按仓别拆开规避风控。
- [x] 系统外买入生成“下一交易日平仓”任务；界面没有伪称可自动向券商下单。
- [x] 继续持有必须在买入当日同时补齐错误条件、止损位、买入依据；缺任一项不放行。
- [x] 未补齐违规头寸每日提醒、同日去重；推送失败不抛出且不标记已提醒；实际清仓后停止提醒。
- [x] 历史仓位与历史场外账不追溯、不改写。
