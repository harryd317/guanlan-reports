# 观澜两线今天页与档案终审设计

日期：2026-08-04  
分支：`ui/today-two-lines-final`

## 目标与边界

本批严格以《观澜原型-定稿-两线今天页-20260804》为视觉和交互标准，把原型中的演示数据替换为现有只读接口的真实数据。改动只覆盖展示层与产业档案工作流，不增加实盘下单入口，不读取或写入真实账户状态，不修改风险参数、T1 快照或生产数据库。

## 方案选择

采用“现有单页前端 + 现有 S8 sidecar 状态机”的渐进方案：

- 今天页和连阳页继续由 `static/home.html` 渲染，连阳数据只读复用 `/api/s8/streak-watchlist`。
- 档案生成继续只写现有 `archive_queue`；在该表上幂等补充 Prompt 版本、生成状态、外部审校和审计 JSON 字段，不新增第四张可写表。
- 正式档案仍以 `docs/产业档案/*.md` 的已提交文件为发布实体；只有状态为 `resolved` 且文件满足规格 v2 的档案才对 S8 门槛生效。
- AI 生成复用现有受控 reviewer 通道。支持联网检索的 Claude Code / Anthropic 通道显式开启搜索；不支持搜索的兼容引擎必须拒绝生成，不能把“仅骨架生成”冒充“AI + web 搜索”。

未采用纯前端 mock 方案，因为它无法形成真实状态流；未新增 workflow 数据库或审计表，因为这会突破已批准的 S8 三表写边界。

## 页面结构

今天页依次为：表头、市况细条、投资线 S8 关注、投机线连阳观察。表头日期与时钟每秒按上海时区刷新，交易状态使用统一的周一至周五交易时段判定。桌面显示数据日，500px 以下隐藏。市况条保持中性色，不挂投资线或投机线配色。

S8 产业芯片来自当天产业级卡片和建档队列，整片跳转对应行业页。连阳卡仅展示真实名单前三条，并显示读法词典；完整名单由 `#streak` 子页承载，`#streak-list` 仅保留兼容跳转。名单为空时如实显示空态，不产生任何操作入口。

## 档案工作流

状态为 `pending/skeleton_ready/draft_ready` 的行业页显示“生成本篇深度研究初稿”。一次请求按顺序执行：

1. 从只读温度计、S8 猎场和已提交研究条目组装数据骨架。
2. 注入服务端只读 Prompt `industry-archive-v2.1-web`，包含规格 v2 七节和样板深度约束。
3. 调用支持 web 搜索的 AI 通道；按钮在请求期间禁用，服务端用原子状态守卫防止重复生成。
4. 对结果执行七节、核心股票数量、来源日期和样板深度校验；不合格结果不进入待终审。
5. 合格初稿落 `archive_queue.ai_draft`，状态转 `awaiting_review`，但不会创建已发布档案，也不会解锁 S8。

待终审页固定显示 AI 初稿警示、镜像投递的 Kimi 四项审校意见，以及发布、退回、改后发布三种终审操作。每次操作向同一队列表的审计 JSON 追加操作人、上海时间、动作和原因。发布动作还必须验证已提交档案文件与规格 v2；通过后状态转 `resolved`，才对 S8 门槛生效。

## 零滚动与响应式

文档根和 body 始终 `overflow:hidden`；`.main` 是纵向 flex 容器，活动 section 占满剩余高度并仅允许自身或指定正文/名单区域内部滚动。所有 grid 直接子项统一 `min-width:0`。窄屏表头保持单行，市况条允许两行，今天页隐藏股票行业小字并收紧芯片和行内边距。

Playwright 对每条路由采用整页重新加载，不依赖同文档 hashchange。冻结视口为 393×852、430×900、1280×900；每条探针同时断言 document 的横纵 `scroll/client` 完全相等。HTML 响应继续带 `Cache-Control: no-store`。

## 安全、失败与回滚

- 所有生产数据源按现有只读连接读取；可写目标仅隔离 S8 sidecar 的既有三表，其中本工作流只改 `archive_queue`。
- AI 或搜索不可用、骨架不足、规格校验失败、镜像审校缺失或发布文件未提交时，状态停在原处并返回明确错误。
- 前端移除生成按钮并不会改变档案或 S8 状态；服务端状态守卫是最终授权边界。
- 回滚只需恢复本批提交并重启应用；sidecar 新增列为向后兼容的可空列，不影响旧版本读取。若需撤销一次终审，按审计日志定位该动作后把队列状态恢复为 `awaiting_review`，已提交档案另走独立 Git 回滚。
