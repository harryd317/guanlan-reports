# 实验记录 · P3c entry_B 复活实验

日期:2026-07-14 凌晨(原定9月,随P3提前;供10-09参数解冻评审)
问题:entry_B(深回调后再突破)五年回测仅 1 笔——是**参数过苛**还是**形态本身稀有**?

## 协议(跑之前写死)

- 引擎:backtest_mid.simulate_mid 在制内变参重放(CONFIG_MID 临时改+复原,
  与 backtest.py --scan 同法);判定函数 rules_mid 零改动(红线);费后口径照旧。
- 变体(单因子放宽 8 个 + 组合温和版 1 个;基线=v5 现行):
  | 变体 | 改动 |
  |---|---|
  | 基线 | 现行参数 |
  | V1/V2 | PB_VOL_SHRINK 0.5→0.65 / 0.8(回调缩量要求放宽) |
  | V3/V4 | REENTRY_VOL 1.2→1.1 / 1.0(再突破放量要求放宽) |
  | V5 | REENTRY_HIGH 20→10(再突破只需10日新高) |
  | V6 | PB_DEPTH_MIN 0.20→0.15(浅一点的深回调也算) |
  | V7 | PB_DEPTH_MAX 0.35→0.45(更深的也算) |
  | V8 | PB_DEPTH 0.15~0.45(窗口两头放) |
  | V9 组合温和 | SHRINK 0.65 + REENTRY_VOL 1.1 + DEPTH 0.15~0.40 |
- 读数:entry_B 笔数 / entry_B 单独期望与胜率(费后) / 全组合期望(entry_A 应零变化,
  作对照自检——A 的判定不吃这些参数)。
- **判定标准(预声明)**:某变体 entry_B ≥10 笔且期望>0 → "参数过苛"成立,该松绑
  方案进 10-09 评审;所有变体都凑不出有意义样本或期望为负 → "形态稀有/不赚钱",
  entry_B 维持现状甚至考虑摘除。
- 纪律:实验只出报告,生产参数一个不动(冻结至 10-09)。

## 结果

### 十个温和变体:entry_B 全部纹丝不动(1笔,-2.73%)

单因子放宽(缩量0.65/0.8、再突破量1.1/1.0、新高窗10日、深度下限0.15/上限0.45/
两头放)与组合温和版(V9),**产量零变化**——连深度窗口两头放宽都一笔没多。
entry_A 恒为 403 笔 +3.76%(自检通过:A 不吃这些参数,仪器无泄漏)。

### 仪器验证(结果可信的前提)

极端放宽(深度1%~99%/缩量不限/再突破量0.01/新高窗3日)→ entry_B **51 笔**:
变参机制工作正常,温和变体的零变化是真实结果,不是机械故障。

### 极端版读数(线索价值)

51 笔 期望 **+2.64%** 胜率 33%;按年:2022 −1.1 / **2024 +109.2 / 2025 +49.2** / 2026 −22.5
——盈利分布在两个年份,非纯 2025 依赖;量级与 entry_A(+3.76%)相当。

## 结论(按预声明标准判定)

1. **"参数过苛"不成立**(温和域内无变体达到 ≥10 笔):v5 的 entry_B 不是"紧了一点",
   是该形态组合在温和参数域内**根本没有产量**——五年 1 笔是形态定义的必然,不是调参问题;
2. 极端版有产量且期望为正,说明"深回调后再突破"**方向不是死路**——但极端参数等于
   取消了大半条件,那是另一个信号顶着 B 的名字,**不许直接上生产**;
3. **供 10-09 评审的两个选项**:
   (a) 摘除 entry_B,系统简化(五年 1 笔的分支是维护负担);
   (b) 以极端实验为线索**重新设计** B 形态(方向:放宽深度窗+弱化量能条件),
   按 11i 流程正式立项:设计段调参→冻结→OOS 验收,不走捷径。
4. 生产参数零改动(冻结纪律)。
