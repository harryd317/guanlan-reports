# 投机线连阳名单胜率与量比关系：测量预声明

## 3. 冻结名单语义

每个名单日按当日可得信息判断，不使用未来数据：

1. 市值 `total_mv >= 5,000,000` 万元；`>= 10,000,000` 万元只作 1000 亿档标记；
2. 名单日上市满 365 个自然日；名单日已退市者排除；
3. 名单日为 ST、`*ST`、退市整理或历史状态无法可靠判定者排除；
4. 剔除上一自然年复权涨幅排名前 10；排名缺失者排除；
5. 必须匹配名单日有效的申万二级行业；
6. 行业温度必须为 `warm` 或 `hot`；`cold`、`scorching`、`unknown` 均排除；
7. 日 K 阳线定义为 `close > open`；最近至少两根有效日 K 连续为阳线；
8. 量比为名单日成交量除以前 20 根有效日 K 成交量均值，分母不含名单日；不足 20 根或分母不为正时记为缺失；
9. 同一代码、同一名单日只保留一行。

历史 ST 处理沿用既有猎场的严格口径：优先使用名单日状态记录和名称区间；无法判定时记录 `st_status_missing` 并排除。上市、退市和行业成员关系均按名单日时点判断。

## 4. 买法与收益口径

### 4.1 观察价与 ±1% 子组

观察价固定为名单日后复权收盘价。本文中的“尾盘 ±1% 内可成交”不模拟盘口或滑点，而是单独标记以下子组：

`-1.0% <= 名单日收盘 / 前收盘 - 1 <= +1.0%`

边界 `-1.0%` 和 `+1.0%` 均计入。正式报告必须并列给出全样本与该子组，不得用子组替代全样本。

### 4.2 固定期限

期限固定为 T+1、T+5、T+10、T+20。T+n 按冻结交易日历向后推进 n 个交易日：

- 个股收益：`目标日后复权收盘 / 名单日后复权收盘 - 1`；
- 胜：个股收益严格大于 0；等于 0 记负；
- 沪深300收益：同一名单日收盘至同一目标交易日收盘；
- 超额收益：个股收益减沪深300收益；
- 不扣费用，不加入滑点。结果是收盘到收盘的毛收益测量，不代表可交易收益。

目标交易日在数据截止之外时，该期限记为 `out_of_calendar`。个股在目标日停牌时，沿用既有研究口径，使用目标日或此前最近一个可靠后复权收盘；从名单日到目标日没有可靠价格则记缺失，不以零填充。

### 4.3 持有期最大回撤

每个期限独立计算收盘路径最大回撤。路径包含名单日观察价和截至 T+n 的每个可靠后复权收盘：

`MDD = min_t(close_t / max(close_0 ... close_t) - 1)`

报告每组的有效数、胜率、平均收益、中位收益、平均超额、中位超额、平均 MDD、中位 MDD 和 MDD 第 10 百分位。

## 5. 固定分组

### 5.1 量比四桶

量比只用以下四桶，边界不得移动：

1. `<0.8`
2. `[0.8, 1.0)`
3. `[1.0, 1.5)`
4. `>=1.5`

量比缺失行计入总名单量和缺失审计，但不进入四桶关系检验。每个桶分别输出 T+1、T+5、T+10、T+20。

### 5.2 辅助分组

- 连阳根数：恰好 5、恰好 6、7 根及以上；2—4 根仍计入总样本和量比表，但不进入该辅助表；
- 行业温度档：`warm`、`hot`；
- 观察组：全样本、±1% 子组。

辅助表只描述分层，不改变主量比结论。

## 6. 单调性与显著性判定

所有检验只使用量比非缺失且对应期限收益有效的样本。

### 6.1 单调性

对每个期限分别按四桶从低到高检查原始胜率：

- 四个胜率非递减，记为“向上单调候选”；
- 四个胜率非递增，记为“向下单调候选”；
- 其他情况记为“不单调”。

同时用桶序号 `0,1,2,3` 对二元胜负做双侧 Cochran–Armitage 趋势检验。四个期限的 p 值用 Holm 法校正。只有原始胜率满足单调顺序且校正后 `p < 0.05`，该期限才判为存在统计显著的单调关系。

跨期限总判定固定为：至少 3 个期限通过显著单调门，且方向一致，才称“存在稳定单调关系”；否则称“没有稳定单调关系”。

### 6.2 显著分层桶

每个期限、每个量比桶与其余三桶合并样本做双侧两比例 z 检验。共 16 次比较，统一用 Holm 法校正。校正后 `p < 0.05` 的桶才称“显著高”或“显著低”；方向由该桶胜率与其余样本胜率之差决定。

“量比越低胜率越高”只在跨期限总判定为稳定向下单调时支持；“量比越高越好”只在稳定向上单调时支持。其他结果一律写为“两种说法都不支持”。

样本量小于 10 的桶或辅助格只列数字，不参加单调、显著性或方向结论。
