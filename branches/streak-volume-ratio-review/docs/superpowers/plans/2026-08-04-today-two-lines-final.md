# 两线今天页与档案终审 TDD 实施计划

> 依据已确认定稿原型实施；每项生产代码前先写能因目标缺失而失败的测试。

## 1. 固化页面与路由契约

- 更新前端模型测试：`#streak` 为规范路由，旧 `#streak-list` 兼容；今天页只包含表头、市况、投资线、投机线四段且顺序固定。
- 增加真实连阳前三条、tooltip、词典、空态和子页回跳测试。
- 先运行目标测试观察预期失败，再按定稿原型最小改造 HTML/CSS/JS。

## 2. 全局零滚动强化

- 扩展生产等效验收矩阵为全部 hash 路由 × 393×852 / 430×900 / 1280×900。
- 测试先验证缺失的横向断言、路由和视口会失败。
- 实施根容器 flex、指定内部滚动、grid 子项 `min-width:0` 与 ≤500px 规则；测试每条路由整页加载。

## 3. 档案生成与审校状态机

- 给 sidecar 迁移和 read model 写失败测试，覆盖 Prompt 版本、生成防重入、四项审校、审计日志与公开状态。
- 给生成编排写失败测试，覆盖自动骨架、仅允许支持 web 搜索的引擎、七节不全不入库、成功转待终审。
- 给终审动作写失败测试，覆盖发布、退回附原因、改后发布、状态守卫和 S8 仅认已发布。
- 实施数据迁移、服务层函数和 FastAPI 接口；外部 AI 在单元测试中只替换网络调用层，真实状态变更与校验保持运行。

## 4. 行业页三态 UI

- 写 DOM/模型测试，覆盖生成按钮、固定警示、只读审校卡、三种终审动作、错误与禁用状态。
- 接入 `archive_queue` 真实 payload 与接口；不把原型股票、数字或审校文案写入生产页面。

## 5. 验收与交付

- 运行目标测试、S8/档案/前端回归和 AGENTS.md 规定的四组全量测试。
- 在生产等效方式启动独立端口，记录生产 plist、生产库和 T1 快照哈希（只读，不改），执行全路由三视口零滚动与截图验收。
- 生成 `docs/验收-两线今天页与档案生成终审-20260804.md`，列出路由矩阵、截图哈希、接口、Prompt 版本、审计字段和回滚方案。
- 提交分支；同步脱敏镜像，用全新克隆校验文件与镜像提交哈希后才报告完成。
