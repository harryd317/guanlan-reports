# 任务7 设计稿：简明模式（两键版投研工具）

> 状态：待产品负责人审阅。2026-07-06 经三轮对话定稿方向。
> 本设计稿用大白话写，因为审稿人就是最终用户。

## 一句话

把现在的"专业驾驶舱"收进抽屉，换成两个按钮的极简界面：
**「今日」告诉你买什么、几块钱买、几块钱卖、买多少钱；「问AI」把每个推荐背后的技术面、基本面、风险讲给你听，还能追问和学习。**

## 你每天怎么用（30秒版）

1. 下午收盘后，手机/电脑弹通知「今日有 2 件事」。
2. 打开工具 →「今日」页，两张卡片：
   - 红卡：「卖出｜沪电股份，明早开盘全部卖掉，因为跌破了止损线 122.5 元」
   - 蓝卡：「买入｜某某科技，明早 39~40 元之间买，买 2.8 万元（约 700 股），止损线 38.2 元」
3. 想知道为什么 → 点卡片上「为什么选它？」，看三段白话（技术面/基本面/风险）。
4. 第二天开盘照做 → 回工具点「已买入/已卖出」，记一笔。
5. 没事的日子打开就一行大字：「今天无操作，持有的票都正常。」看完即走。

## 页面一：「今日」（推荐 + 追踪）

从上到下四块：

### 1. 今天要做的事（消息卡，没事就显示「今天无操作」）

**买入卡（蓝）**——回答"买什么、几块钱买、买多少":
```
买入｜某某科技 601234
买点:39.0~40.0 元之间（今收 39.5）
买多少:建议 2.8 万元（约 700 股）
止损线:38.2 元（跌破就卖，最多亏账户的 2%）
怎么做:明早开盘在券商App买入 → 回这里点「已买入」
[为什么选它？▾]  [已买入]  [这次不买]
```
- 「买多少」按你设置的账户总额和"单笔最多亏 2%"自动倒算，不用心算。
- 「为什么选它？」展开就是**学习区**（见下）。

**卖出卡（红，永远置顶）**：
```
卖出｜沪电股份 002463
卖点:明早开盘卖出全部
原因:昨天收盘 121.8 元,跌破了你定的止损线 122.5 元。
     止损是纪律:亏小钱离场,才有钱等下一次机会。
[为什么要止损？▾]  [已卖出]
```

**落袋卡（金，止盈减半）**——回答"什么时候止盈"：
```
落袋｜某某医药 600YYY
怎么卖:明早开盘卖出一半（约 350 股），落袋约 +8000 元
剩下一半:继续持有，卖出线抬到 47.90 元
原因:三周涨了40%,昨天放天量却涨不动——涨太急先歇脚,
     落袋一半,剩下的让利润继续跑。
[为什么不全卖？▾]  [已卖出一半]
```

**止盈的呈现原则（重要）**：这套规则的止盈不是固定价格，而是一条**自动上移的
「卖出线」**（取四条规则的最高触发价：止损线→保本线→最高点回撤25%线→30周生命线）。
界面上处处只用「卖出线」这一个词：
- 买入卡加一行「什么时候止盈：赚了后卖出线自动上移，每天报给您」；
- 持有列表每行显示当前卖出线数字，并标注状态：「已抬过成本，这单亏不了」/「已锁住利润」；
- 跌破卖出线 → 出红色卖出卡；触发天量滞涨 → 出金色落袋卡。

**新机会卡（灰）**：
```
新发现｜某某电子 600xxx
昨天放量创了一年新高,进入观察名单。要不要让 AI 写份研究报告?
[要,研究一下]  [不要]
```

**复核卡（黄）**：
```
提醒｜沪电股份出了扩产公告
AI 看过了:这个消息**支持**当初看好它的理由,不用动。
[细看AI的分析]  [知道了]
```

### 2. 我持有的

每只一行白话＋红绿灯：
`沪电股份 ｜ 现价 135.4 ｜ 赚 +6.2% ｜ 离止损线还有 9.5% ✅安全`
红灯 = 系统已下卖出指令（对应上面的红卡）。

### 3. 等买点的

`某某科技 ｜ 等它回调到 39 元附近缩量企稳,到了我在这里叫你`

### 4. 底部折叠（想看才点开）

我的战绩（多少笔、胜率、赚亏）｜完整日报｜专业看板入口。

## 「为什么选它？」——长在每张卡上的学习区

点开后三段，每段 3~5 句白话，**这是"学习"功能的主体**：

1. **技术面**（嵌 K 线图，把说到的位置画在图上）：
   「它 6 月 20 日放量创了一年新高（图上▲），说明有大资金进场。之后缩量回调到突破位附近不再跌（图上◯）——像退潮时看谁在裸泳，缩量说明没人抛售。这就是我们等的买点。」
2. **基本面**：
   「最新业绩预告净利润同比 +80%；AI 研究报告给它打 28/35 分，看好的核心理由是：____（来自立项报告的多头论点）。」
3. **风险（这单会怎么亏）**：
   「三种失败剧本：____（来自空头报告三路径）。所以止损线定在 38.2——判断错了最多亏 2%，认错离场。」

三段的数字全部来自规则引擎和已存的研究报告（AI 只负责把它们讲成人话，不许改数字）。每段末尾有「没看懂？问AI」按钮，一键跳到页面二接着问。

## 页面二：「问AI」（股票池 = 课程目录，每只票 = 一堂课，AI = 助教）

**结构（自上而下）：**

### 1. 我的股票池（横向小卡，按你的规则筛出来的）
`某某医药(持有中 +38.5%)｜华虹科技(今日买点●)｜某某科技(等买点)｜某某电子(新发现)`
——这就是"课程目录"。点谁，下面就讲谁。

### 2. 「这一课」（点一只票自动生成的学习档案，三段）
- **① 它是做什么的，行业怎么样**：主营业务一句话 + 所在行业的位置与景气度
  （行业趋势用行业指数30周均线状态做依据，哪些是数据哪些是观点分开说）
- **② 技术面怎么看它**：嵌它的**真实K线图**，买入点▲、突破位、卖出线都画在图上；
  配白话讲解"为什么规则选中它 / 现在处于什么阶段 / 跌到哪会走"
- **③ 基本面怎么看它**：最新业绩 + AI研究报告摘要（评分/多头逻辑/三条风险），
  可展开完整研究报告

### 3. 就这只票追问（对话区）
输入框自动带着这只票的完整资料（池状态/关键位/论点/事件/日报），
问"涨了38%还能加仓吗"这类问题，AI 用你的规则来回答。对话按天保存。

### 4. 底部快捷键
分析一个行业｜教我一个概念｜池外的票也能查（输代码即可）

**课文生成规则**：三段课文由 AI 基于系统注入数据生成（复用个股上下文通道），
**数字一律来自注入数据不许编**；每票每天最多生成一次并缓存（成本护栏），
数据没变就直接读缓存。没有AI研究报告的票，第③段显示「还没研究报告，点一下让AI写」。

## 不变的底线

1. **所有买卖点的数字来自规则引擎**（收盘数据决定性计算），AI 只解释不改数——你的原话："机械层指令不被 AI 改写"。
2. **下单的手永远是你的**：工具只下指令、讲道理、记账。
3. 旧五页、全部规则、三份测试**原样保留**，简明模式是加一层，不是推倒。
4. 买卖点的本质是"你定的纪律被触发"，不是预测。工具承诺的是纪律执行和讲明白道理，不承诺每单赚钱——学习区第一课就讲这个。

## 技术实现概要（给开发看的，你可以跳过）

- 新模块 `brief.py`：决定性翻译层（纯函数）——日报 next_action / 池状态 / AI解读 → 消息卡 JSON；术语词典；仓位建议 = f(账户总额 ACCOUNT_SIZE, 2%风险, 现价, 止损价)。全部可离线测试。
- 新接口 `GET /api/brief`（今日页数据一次取走）、`POST /api/brief/act`（已买入/已卖出/要研究/不要 四个按钮的落点，内部走现有 pool_transition / close_position / thesis 生成，不新造状态机）。
- 新页面 `static/home.html`（今日）与 `static/ask.html`（问AI，复用现有 chat 接口 + stock_detail 的图表组件）；`/` 指向 home.html。
- 「为什么选它」三段：技术面=规则引擎判定结果的模板化白话 + 现有 K线接口；基本面/风险=已存 thesis 的 bull_case/bear_report + 最新业绩事件；无研究报告时显示「还没研究报告，点一下让AI写」。
- 「这一课」：新接口 `GET /api/lesson/{code}`——AI 基于个股上下文（复用 build_stock_context）生成三段课文，按 (code, 交易日) 缓存（新表 lessons 或 storage 键值），每票每天最多生成一次（成本护栏）；数字来自注入数据，生成后做数字一致性抽查（课文里的价格必须能在注入数据中找到，防编造）。
- 股票池条：pool_list + 白话状态词典（同页面一）。
- 学习问答、行业分析:复用 reviewer.chat 加 usage_purpose 分列(learn / industry / lesson)。
- 旧导航五项收进齿轮;test_web 的导航用例(T5F1)按新规格更新并补简明模式用例。
- 照旧:严格 TDD;完成后三测全绿;真实浏览器渲染验证;完成报告。

## 验收标准（你来验，全是白话）

1. 打开工具 10 秒内知道"今天要不要动手、动哪只、几块钱"。
2. 每张买入卡都有价格、金额、股数、止损线，点开能看懂"为什么"。
3. 一个黑话都看不到；看不懂的地方都有"问AI"入口。
4. 没事的日子打开就一行"今天无操作"。
5. 点「已买入/已卖出」后，持仓和战绩自动记上，不用去交易台手工录。
6. 旧页面都在齿轮里，功能一个没少。
