## 三、审查(15 agent 敌对验证)确认并修复的问题(7条,1条误报驳回)

1. **[major] 过期候选静默查错票**:SUGG_HITS 不绑定查询串,改词后回车拿旧候选跑体检。修:suggInput 立即作废旧候选 + SUGG_Q 绑定校验;
2. **[major] 名录拉取失败无冷却**:Tushare 故障时每次联想都 `_retry` 睡 6~9 秒占线程池。修:fail_ts 冷却 600s + tries=1;
3. **[major] 生产 8787 跑旧后端**(新前端+旧后端错配,联想 404):已 kickstart 并验收——**教训固化:改 service.py/data.py 必须 kickstart 生产实例,只改静态文件才免重启**;
4. [minor] suggClose 不递增代次,在途响应会把关掉的下拉重新弹开。修:suggClose 里 SUGG_SEQ++;
5. [minor] 全角输入(６００５/ｃｃｋｊ)0 命中且提示误导。修:NFKC 归一 + T13D 用例;
6. [minor] leglist 宽度不自愈(渲染时子屏隐藏 clientWidth=0 被钳 200px;旋转/缩放不重算)。修:fit() + ResizeObserver 观察 tablewrap;
7. [minor] rAF 在后台标签页挂起导致钉屏初始化延迟。修:去 rAF 改同步执行(读 clientWidth 本身强制布局)。
