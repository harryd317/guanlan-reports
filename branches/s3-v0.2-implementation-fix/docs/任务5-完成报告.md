## 对抗审查修复轮(多代理审查确认的 7 条缺陷,已全部修复+测试钉死)

1. **[major] 混合态孤儿仓**:池里有任一 holding 时,交易台手录持仓被排除出出场检查/日报/盘中监控且零提醒
   → 新增 `_orphan_position_alerts()` 修数据提醒行(T5R1)。
2. **[major] 论点轮询打行情接口**:生成报告期间每8秒整页重建K线卡→重复全量拉520日行情(有触发东财
   分钟窗封禁的风险)+图表闪烁清零 → 轮询只刷论点卡(T5R6)。
3. **[minor] pool_upsert_holding 覆写 note/重置 state_since**:重复导入会清用户备注、让日报把老持仓
   误报成「今日迁移」→ note 空才写默认、已是 holding 不动 state_since(T5R2)。
4. **[minor] 冷却票可被导入复活**:绕过20交易日冷却纪律 → cooldown 拒绝并进导入 errors(T5R3)。
5. **[minor] 个股上下文命中周报**:周六后 daily_card 恒空并注入假话 → 跳过 weekly/无 cards 的行(T5R4)。
6. **[minor] key 跨截断边界泄漏前缀**:先截断后消毒会把 key 切半使替换失效 → 三处改为先消毒后截断(T5R5)。
7. **[minor] 前端契约**:周K高亮失同步/fetch 无过期响应保护/导入 errors 被丢弃 → FREQ 高亮+请求代次+
   errors 渲染(T5R7/R8)。
