## 真实通电验收实录(2026-07-06,gpt-5.5)

排障链路(每一步系统都给出了人话错误,零白屏零泄密):

1. **HTTP 429 额度不足** → API 计费与 ChatGPT 订阅是两回事,用户在
   platform.openai.com Billing 充值后消除。
2. **HTTP 404 模型不存在** → 用户填了大写 `GPT-5.5`;API 模型名区分大小写。
   用 `/v1/models` 现查该 key 可用清单(118 个)确认 `gpt-5.5`(2026-04-23 版)存在,
   改小写后消除。
3. **HTTP 400 temperature 不支持** → gpt-5.x 推理类模型只接受默认 temperature。
   这是通道代码问题,按 TDD 补 T6A7 用例后修复(自动去参重试)。
4. **✓ 真实复核成功**:池内票 002463 沪电股份,「问 AI 复核此票」返回完整纪律复核。

回答质量验收(产品负责人视角的四个硬指标全过):

- **只用注入数据**:引用的全是系统注入的真实数字(回踩低点 125.88 未破平台 122.54、
  当日量 87.35万手 < 20日均量 92.19万手、大盘距 MA60 仅 +0.18% 踩线预警);
- **抓住真实纪律冲突**:指出平台止损距离约 9.5% 超过规则5「入场价-8%」上限,
  提示两者取先到者——这正是二审员的核心职责;
- **守住边界**:不下买卖指令、明确拒绝为放宽止损背书(引用规则5)、
  资金流/龙虎榜无明细数据就直说不编造;
