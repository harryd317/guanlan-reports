# 交付总结 11d:仓位硬闸门(2026-07-09)

> 自包含总结,可直接转发。体检批次第 5 件;原型经拍板(A 金额必填 / B 超线强确认)。

## 修的是什么问题(体检 high 级)

规则卡写着三道仓位纪律(单笔风险2%、单票≤30%、总仓≤60%),但代码里**没有一道会拦人**:
点「已买入」时零校验,总仓爆到 100% 系统一声不吭——"纪律投研台"的核心卖点在仓位维度
不成立。更底层的缺陷:买入时连**金额都不采集**(只填成交价),仓位算不了,净值曲线
和盈亏统计也一直缺真实数据。

## 做了什么

1. **买入必填金额**(拍板A):确认条从"成交价"一个框变成"成交价 + 买了多少钱(万)"
   两个框;金额随买入落库(顺手治好净值曲线缺数的老病);
2. **两道硬校验**(上限=设置页参数 POS_MAX_PCT=30 / TOTAL_MAX_PCT=60,可调):
   - 单票:这笔金额 ÷ 账户总额 ≤ 30%;
   - 总仓:(已知持仓金额合计 + 这笔)÷ 账户总额 ≤ 60%;
   - 超线红字拒绝,写明超了哪条、超多少、最多还能买几万,并提醒
     "改上限请冷静时去维修间,不要在想买的时候";
3. **超线强确认**(拍板B):红字下方出现「我明白,仍要买入(超线)」按钮,再点一次
   放行——但会写一条 `force_buy` 审计记录(何时、何票、何价),破例有痕;
4. **前提兜底**:没填账户总额 → 拒绝并引导去 ⚙️ 填(一次性);老持仓没填金额时
   总仓按已知部分算并如实注明,不装精确。
