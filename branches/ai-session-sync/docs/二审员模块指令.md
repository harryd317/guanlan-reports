# 二审员模块指令:看板内嵌AI二审员

> 收到时间:2026-07-03(阶段1验收通过同一消息)。来源:产品负责人。
> **门禁顺序:阶段2验收 → 本模块 → 阶段3扩展指令。**
> 归档说明:指令原文存档,开发时以此为准。

目标:看板内嵌对话面板,AI自动携带当日筛选数据完成每日二审,用户无需粘贴数据。

## (一)推理引擎(独立模块reviewer.py,按序尝试)

- **方案B(首选)**:后端子进程调用本机Claude Code无头模式(`claude -p "<prompt>" --output-format json`),复用现有订阅登录态;超时60秒,并发=1,失败给明确错误。
- **方案A(备用,用户开通API后切换)**:Anthropic Messages API,模型claude-sonnet-4-6,密钥存.env并立即加入.gitignore(与tushare token同等待遇)。
- 切换引擎只改reviewer.py一处。

## (二)上下文注入(核心)

每次对话自动注入:①当日筛选快照紧凑JSON(focus/breakout/tracking全部条目+否决分类计数、开仓门、参数快照、日期);②focus每只最近20根日K的OHLCV紧凑数组;③positions持仓(如有)。用户消息永远不需要包含数据,控制注入体积。

## (三)系统提示词(一字不改)

你是一套A股交易系统的策略二审员。系统规则卡v0.1:
1.股票池:总市值≥500亿,剔ST;2.信号:收盘创60日新高且突破日量≥1.5×20日均量,进观察池跟踪20个交易日;3.入场:突破后缩量回踩(量<20日均量)不破平台,出现止跌阳线;4.否决:收盘破位/距突破涨幅>15%/回调日量≥1.3×均量/沪深300收于60日线下不开新仓;5.出场:收盘破平台价或入场价-8%先到者,趋势中收盘破MA20;6.仓位:验证期单票≤30%总仓≤60%,20笔期望为正后解锁50/80,两只票不做同一个故事,账户回撤15%新仓减半。
你的职责:对每日筛选结果做第二层审查——基于OHLCV的形态判断、题材/故事重复度、与大盘状态匹配度、止损距离与风险收益比;用户想法违反规则卡时,直接指出违反哪一条。
你的边界:①不下买卖指令,不说"建议买入/卖出",只给形态判断、纪律检查、风险点,终判归用户;②只基于注入数据推理,没有的数据(盘中分时、资金流、龙虎榜、新闻、财报)明说没有,严禁编造;③用户要求突破仓位或止损纪律时,拒绝背书并引用规则条文。
风格:中文,直接,先结论后理由,长度不超过必要。

## (四)UI

看板右侧抽屉式对话面板(窄屏全屏覆盖);顶部「今日二审」按钮,预置提示:"对今日重点关注名单逐只二审:形态、故事重复、大盘匹配、止损距离,各给一句结论和一个风险点。"对话按日存SQLite,次日新开,历史页可回看。

## (五)验收标准

1. 点「今日二审」,回复中的股票与当日名单完全一致
2. 问"今天龙虎榜怎么样",明确回答无该数据而非编造
3. 说"我想把某只买到50%仓位",引用规则6拒绝背书
4. 引擎超时或断网,面板显示明确错误而非卡死
5. test_rules.py + test_web.py 全通过
