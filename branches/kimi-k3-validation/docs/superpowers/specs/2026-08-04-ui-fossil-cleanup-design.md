# 界面化石清理设计

**日期：** 2026-08-04  
**状态：** 用户已给出完整规格并授权实施  
**边界：** 只清理展示与冻结旧自动入口，不改数据库内容、S2/S8 判定、风控、交易或行情管道

## 1. 方案选择

采用“分区展示 + 统一冻结闸”方案。

- 股票池前端按来源分为 S8、人工和 S2 遗产三组；S2 遗产使用原 `/api/pool` 数据，不迁移、不改行。
- 今天页只过滤 S2 遗产的展示，不改变遗产行的自然过期任务。
- 连阳名单保留原只读子页和接口，只把入口从今天页移到选股逻辑卡。
- 旧 AI 自动研究和自动入池代码、参数、测试夹具全部保留；所有自动入口先经过同一只读冻结状态，冻结时不生成论文、不迁移池状态、不写备注。

备选方案一是删除旧引擎代码，会破坏“只归档不删除”；备选方案二是只隐藏界面，会留下仍可运行的自动入池写路径。两者均不采用。

## 2. 股票池名单

名单页固定顺序为：

1. `S8观察池`：读取现有 `/api/s8/observations`。当前无观察时显示“当前暂无 S8 观察标的”。
2. `人工观察`：显示 `/api/pool` 中非 `s2_legacy` 的人工行；空时不伪造内容。
3. `S2遗产（到期自动退出）`：显示 `/api/pool` 中 `strategy === "s2_legacy"` 的行，使用原生 `<details>`，默认收起。

遗产行继续显示原股票、状态、现价、距买点和行业。新增到期文案按界面数据日计算：未来日期显示“剩 N 天”，当天显示“今日到期”，已过期显示“待自动退出”，缺日期显示“到期日未知”。该计算只作展示。

股票池总数仍按三组去重后的真实行数显示。详情路由保持不变。

## 3. 今天页

- 英雄区删除红利低波卡，只保留真实运行的投机线开仓门/市况卡。
- 选股逻辑页保留红利低波卡，增加徽标“想法冻结 · 未建仓”。文案、计划常量和数据不改。
- “等买点”和“待处理”在展示层排除 `s2_legacy` 代码；没有其他行时显示原诚实空态。
- 删除连阳摘要卡。今天页不再触发连阳名单读取；子页按需进入时读取。

## 4. 连阳入口

`#streak-list` 子页、表格、只读边界和详情返回保持不变。第三张选股逻辑卡新增“观察学习用途 · 查看连阳名单 →”按钮。点击后进入 `#streak-list`；从名单进入个股详情后仍返回名单。

## 5. AI 自动入池冻结

统一状态常量为 `AUTO_POOL_CHANNEL_FROZEN = True`。

- `eod._auto_research()` 在读取候选、生成 AI 研究或迁移状态之前返回：`processed=0`、空结果、`frozen=true`。
- `reviewer.auto_pool_decision()` 在读取池行或写库之前返回“已冻结（仅归档）”。
- 手动建池接口、人工状态迁移、S8 信号三表和 S8 观察读取不经过该冻结闸，不受影响。

最后运行时间以生产日志中最后一条成功“自动研究/自动入池判定”记录为主证据，以生产只读数据库相应行的 `updated_at` 为交叉证据。冻结部署后再次扫描日志，证明没有新成功记录。

## 6. 测试与验收

先写失败测试，至少覆盖：

- 三分区、S2 默认收起、9 行真实遗产和倒计时四态；
- 今天页不含红利低波英雄和连阳摘要，S2 不进入等买点/待处理；
- 逻辑页冻结徽标和连阳子页入口；
- 冻结状态下 `_auto_research`、`auto_pool_decision` 均不调用数据库写函数；
- 人工与 S8 入口仍存在；
- 既有 20 页面双视口零滚动矩阵继续完整通过。

部署前使用生产 LaunchAgent 克隆、同一启动脚本和只读数据库副本。记录生产 plist、生产库、副本库、静态文件和服务文件 SHA-256。生产部署后复测健康检查、双视口和哈希；异常立即回滚。
