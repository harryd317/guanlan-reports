# 今天页两线冠名修正设计

## 目标

修正今天页对 S8 投资线与市况基础设施的归属表达，不改数据、引擎、卡片内容、路由或选股逻辑页三张卡。

## 冻结文案

1. 今天页 S8 区块主标题为“投资线 · S8 关注”。
2. 该区块在主标题下显示固定副标“产业核心股研究信号 · 供学习 · 非交易建议”。
3. 今天页市况英雄卡标题为“市况 · 开仓门”，不出现“投机线”。
4. 选股逻辑页的两张投资线卡和一张“投机线 · 已证伪”卡保持现状。

## 实现

只修改 `static/home.html` 今天页两个现有静态节点：

- `#s8-focus` 的 `<h3>` 更新主标题，并在标题与 `#s8-cards` 之间增加可见副标节点。
- `#spec-key` 只替换可见文字。

副标复用现有弱文字颜色，不增加新容器、交互或高度级别。不修改 JavaScript 数据流、API、数据库或调度任务。

## 验收

- 先在 `test_guanlan_frontend.py` 增加 DOM 级可见文案契约，验证新冠名、副标、旧冠名消失和三张选股逻辑卡不变。
- 测试必须先因旧文案失败，再作最小 HTML/CSS 修正。
- 仓库强制回归全部通过。
- 生产等效环境使用 LaunchAgent 克隆副本、独立端口和只读数据库副本；取证原 plist、生产库与副本的启停前后 SHA-256。
- 在 `1440×900` 和 `390×844` 下重跑全页面零滚动断言，并回传今天页双视口截图。
- 部署后重复生产健康、哈希、零滚动和双视口验收；最终报告提交后同步镜像，从全新克隆复核并回报镜像哈希。
