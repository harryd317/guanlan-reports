## 2. 页面验收

### 2.1 今天页

今天页按定稿顺序渲染四段：

1. `今天`、上海日期、实时走秒时钟、交易状态和桌面数据日；500px 以下隐藏重复的数据日。
2. 中性色市况条；不挂投资线或投机线配色。
3. `投资线 · S8 关注`；产业芯片读取 `/api/s8/today` 与 `/api/s8/archive-queue`，整片进入对应行业页。
4. `投机线 · 连阳观察`；读取 `/api/s8/streak-watchlist`，首页只展示前三条真实结果，保留量比说明、读法词典和完整名单入口。

验收时连阳接口返回 `ok=true`、数据日 `2026-08-04`、真实结果 82 条。页面没有写死原型的 7 只演示股票。接口为空时显示空态，不产生操作入口。

### 2.2 连阳观察子页

规范路由为 `#streak`，`#streak-list` 只做兼容跳转。子页展示完整真实名单，返回今天页；页脚固定显示“纯名单 · 不触发信号 · 买法已经 S7/S9 证伪”。名单区可以内部滚动，文档根不滚动。

### 2.3 行业档案页

页面保留排队、研究中、待终审和已发布状态。排队或研究中状态显示“生成本篇深度研究初稿”；待终审状态显示固定警示、Kimi 四项审校意见和三种终审操作；已发布状态显示正式 Markdown 档案。

生产等效环境使用只读数据库副本，因此没有执行会写入队列的生成或终审操作。已发布态和研究中态用真实只读数据完成视觉验收；待终审路由完成零滚动验收，状态专属行为在临时 `S8_research.test.db` 中通过自动化测试，没有向生产等效环境注入演示记录。

## 3. 档案生成与终审

### 3.1 接口

| 方法与路径 | 用途 | 写入边界 |
| --- | --- | --- |
| `POST /api/s8/archive-queue/{industry_code}/generate` | 组装真实骨架、调用联网 AI、校验并保存初稿 | 仅 `archive_queue` |
| `POST /api/s8/archive-queue/{industry_code}/review` | 接收 Kimi 经脱敏镜像投递的四项只读审校意见 | 仅 `archive_queue` |
| `POST /api/s8/archive-queue/{industry_code}/finalize` | 发布、退回或改后发布 | 仅 `archive_queue`；正式档案必须已提交 |

生成接口采用队列状态单飞锁。重复请求返回冲突；失败时状态恢复为 `skeleton_ready` 并保留截断后的错误。前端在请求期间禁用按钮。

### 3.2 数据骨架与 Prompt

数据骨架来自只读温度计快照、S8 日输入、行业成分股和已提交产业研究。Prompt 只保存在服务端，前端不可读写。

Prompt 模板版本：`industry-archive-v2.1-web`。

模板强制七节：温度计读数与数据日期、产业是什么、周期与位置、资金逻辑、核心股票不超过 5 只、风险与诚实边界、证据与来源。生成通道只允许支持联网搜索的 `claude_code` 或 `api`；其他引擎明确拒绝。数字只能来自注入骨架或带来源的搜索事实。七节缺失、核心股超限或深度不足时，草稿不进入终审。

页面固定显示：`AI 生成初稿 · 未经审校/终审不作为核心股依据`。生成只产生初稿，不发布档案，也不解锁 S8。

### 3.3 审校、发布和审计

外部审校必须同时提交四项字段：

- `facts`：事实
- `specification`：规格
- `logic`：逻辑
- `conclusion`：结论

审校请求必须携带已验证的 40 或 64 位镜像提交哈希。发布和改后发布还必须满足三项条件：外部审校已落库、镜像哈希已验证、正式档案文件已提交且通过规格 v2 校验。发布后队列状态才转为 `resolved`；S8 档案门槛只认该已发布状态。

每次审校或终审向 `audit_log_json` 追加：

- `actor`：操作人
- `time`：带时区时间
- `action`：`external_review`、`publish`、`return` 或 `edit_publish`
- `reason`：原因；退回时必填

## 4. 全局零滚动
