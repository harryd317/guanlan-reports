## Task A: backtest_endorse.py 策略×市况矩阵(§6.1 全规格)

**输入**:短线 reports/backtest_trades_20260713_1821.csv(费后0.15%)+
中线 reports/backtest_mid_trades_v5params.csv(费后,v5参数)× regime_history(按 buy_date 归段)。

**规格逐条(§6.1,一条不减)**:
1. 准入资格只看分类器 OOS 段(2022-01-01 起)的成绩;训练段(2015~2021)仅参考列灰显
   ——防"分类器定义内含哪段行情赚钱"的同义反复;
2. 主排序指标=**费后日均收益率**(Σpnl_pct÷Σhold_days,跨长短线唯一可比口径),
   期望/笔只作辅助列绝不参与排序;
3. **资格门槛五条缺一不可**:①分段样本≥30笔;②来自≥3个不相邻同市况区段
   (区段=regime_history 连续段,天然不相邻);③单一区段利润贡献≤50%;
   ④剔除最佳单一年份后期望仍>0;⑤按区段 block bootstrap(整段重抽1000次)
   费后期望95%置信下界>0;
4. 每格强制展示:置信区间/区段数/最大单段利润占比/按年分解;不达标显示
   「背书不足」而非裸点估计——**接受大部分格子长期是灰的,诚实不是缺陷**;
5. 重算触发=新增实盘≥20笔或引擎改版(非日历仪式),重算留审计痕。

**产出**:console 摘要+HTML 报告(reports/endorse_<stamp>.html,标注数据截止日与
regime 引擎版本)+实验记录。矩阵 JSON 落 reports/(P3b 消费)。

**归段口径**:按 buy_date 对 regime_history 的当日标签(entry决策日=买入日;
buy_date 无标签的笔剔除并诚实计数)。

## Task B: backtest_switch.py 整机端到端回测(§6.2 全规格,P4 准入闸门)

- **as-of 矩阵**:每个历史日只用截至当日的 trades+regime 重算资格(禁终局矩阵防前视);
- 完整模拟:判市况→查矩阵→任期约束→切换→新开仓新策略/老仓旧策略→
  最小仓稀释→管道空窗→组合级费后净值;
- **双基准**:①一直中线卡;②中线+现有开仓门二态(两行代码对照组);
- 准入:费后跑赢两基准且回撤不劣;**跑不赢=全自动永久免谈**;
- 附:每次切换的边际盈亏分解+"降级后存量持仓后续回撤"单列;
- 超参敏感性网格(任期{5,10,20,40}×滞回{2,3,5}×带宽{0.5,1,2}%),
  **取绩效平台区中心非最优点**;排序随参数翻转=结构性脆弱,不予上线。
