# 实验记录 · P2 先导任务:短线回测补双边费用 + 重跑

日期:2026-07-13
起因:量化审查原始约束——P3 背书矩阵消费前,长短两回测引擎口径必须统一。中线 backtest_mid 自 11g 起就是费后口径(口径7:FEE_PCT=0.15 双边打包),短线 backtest.py 一直费前。

## 改动

- `backtest.py` 新增 `FEE_PCT = 0.15`(佣金+印花税+滑点保守打包,与 backtest_mid 口径7逐字一致);simulate/run/报告全链带 fee 参数,已平仓与持有中估值行同扣(与中线一致,宁可保守);`--fee 0` 复现旧费前口径作对照。
- `test_web.py` W69 改版:期望值钉住"毛收益−FEE_PCT",顺带钉死费用常量本身。三测 8/20/500。

## 实证(改动正确性)

同一份缓存数据费前/费后各跑一遍:**1190 笔逐笔差值恰好 0.15,笔数/跳过数完全一致**——除费用外零行为变化。

## 正式重跑(数据刷新至 2026-07-13,耗时 550s)

**开仓门:开(纪律口径,费后 0.15%)**
- 已平仓 1102 笔(持有中 8;高开放弃 10;门关跳过 1053)
- 胜率 27.9% | 均盈 +10.01% | 均亏 −3.07% | 盈亏比 3.26
- **期望 +0.59%/笔 | 累计 +646.9%(单利等额) | 最大回撤 −466.5% | 中位持有 4 天**
- 按年:2021:−137% / 2022:−168% / 2023:+4% / 2024:−74% / **2025:+892%** / 2026:+130%
- 出场:破平台止损×610 / 破MA20×490 / −8%止损×2

**开仓门:关(对照组,费后)**
- 1583 笔 | 胜率 26.9% | 期望 +0.40%/笔 | 累计 +638.3% | 最大回撤 −636.2%

## 结论

1. **费后短线期望仍为正(+0.59%/笔)**,费用未改变策略性质(费前口径旧数为 +0.7 上下量级,扣 0.15 后逻辑自洽);
2. **开仓门持续有效**:开 +0.59 vs 关 +0.40,且最大回撤 −466% vs −636%——门既提期望又减回撤,与历次结论一致;
3. **盈利集中度与中线同病**:2025 一年 +892% 撑起全部,2021/2022/2024 均为负——短线卡若要启用,同样需要市况背书(这正是 P2/P3 要回答的问题);2026 年内 +130% 为正,与中线 11i 修正后的年内表现方向一致;
4. 两引擎口径已统一(双边 0.15% 费后),**P3 背书矩阵的口径前提就绪**。
