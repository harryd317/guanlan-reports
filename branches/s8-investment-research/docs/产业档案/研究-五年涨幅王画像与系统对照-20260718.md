## 0. 口径(先于结论写死)

- 数据源:market.db 全市场日线(2015→2026-07-17)× adj_factors 后复权;年度涨幅 =(当年12月最后收盘×复权)/(上年12月最后收盘×复权)−1;
- 剔除:当年上市新股(上年12月无行情自动剔);北交所票(流动性/开户门槛/500亿猎场结构性不覆盖,主榜剔除、附录留名);302132 与 300114 为同一票(中航电测重组更名成飞、创业板转主板改码,数据库双码同史,去重取 300114);

- 系统交叉:reports/backtest_mid_trades_v5params.csv(459笔冻结重放)按 code 匹配;猎场归属查 bt_cache.db bt_universe(季度截面市值,500亿口径);

## 2. 物种分类:涨幅王是三种动物

- **A 题材连板妖股**(九安、圣龙、捷荣、高新发展、汇金、西安饮食):游资筹码游戏。启动=突发事件(FDA/Mate60/算力订单),形态=横盘无量→一字连板,**不给第二买点**;启动时市值 30~200 亿。
- **B 借壳/重组一次性重估**(上纬、天普、宇顺、亚振、绿康、中航电测):一纸公告改变公司性质。中航电测 26 天走完全年涨幅是极端标本。启动前市值 30 亿级。
- **C 产业趋势核心股**(湖北宜化、联创、江特、宝明、传艺、联特、中际旭创、寒武纪、正丹、罗博特科、万丰、胜宏):真实供需/技术变革,主升 **150~220 个交易日(7~10个月)**,一路有平台-回调-再突破的节奏,**给纪律系统入场机会**。

### 3.3 血点定律(本研究最硬的副产品)

25只涨幅王的年内启动低点高度集中在**大盘恐慌底**:2022-04-26/28(上海疫情底)、2024-02-05/07(微盘股流动性危机)、2025-01初与04-07(对等关税暴跌)。**涨幅王的买点=市场的血点**。这正是市况引擎的用武之地:恐慌底门关(不接刀),恐慌解除门重开的第一批信号里就有未来的涨幅王——胜宏 2025-02-18 被系统买入正是1月恐慌后门重开期。

## 4. 深入思考(结合系统)

1. **不要用A/B类的涨幅给系统记罪**。连板妖股和借壳的利润对纪律系统是"幻影利润":买不进(一字板)、拿不住(开板即巅峰)、不可重复(公告不可预测)。追它们的散户整体是筹码游戏的出口。系统对它们沉默是特性,不是缺陷。
2. **C类核心股每年都有,而且大行情年必有500亿+的**(2023旭创、2024寒武纪、2025胜宏)。猎场没问题——**问题在"抓到了拿不住"**:寒武纪2024吃14.5pp/全程388%,胜宏2025四进四出约0/全程586%。病灶三处:E3锁盈触发太早、高位追入被E1震出、无留仓机制吃主升后段。
3. **36格审判(留⅔+dd25)正是治这个病的药**,本研究是其最强实证注脚:核心股主升7~10个月,而系统中位持有26天(11i后)——留仓制度把持有周期从"周"级拉向"月季"级才匹配猎物的节奏。旭创2026那笔+83.9%持有5个月(11i新参数下),证明方向已对,阶梯是下一刀。
4. **第二年魔咒**:昨日涨幅王次年均值回归(罗博特科案例:系统2026抓两笔全亏;九安2022-04后腰斩再腰斩;正丹2024下半年腰斩)。长线画像的"首捕"项在数据上再获一层意义;可列观察项:池内票若为"上年涨幅榜前列+已翻倍后进池",谨慎对待。
5. **市值门槛500维持不动**。降到300也覆盖不了主流妖股(启动时30~100亿),只会引入小盘噪音,且全部回测背书在500口径("证据在哪,猎场就在哪",07-18市值门槛研究同款结论)。若真要研究低门槛,须新建缓存+预声明协议,另立实验。
6. **血点定律的制度化含义**:大盘恐慌底(市况=恐慌下跌/高波震荡)后门重开的第一个月,是核心股起飞的高发窗——门重开日的信号质量值得未来专项统计(样本:2024-02、2024-09、2025-01、2025-04 门重开后30日内信号的后续表现)。

## 5. 诚实边界

- 板块/概念/催化为领域知识归因,非数据库字段;天普股份、亚振家居两只壳妖的具体运作细节把握不足,已标注;
- "买点"为后视镜口径(年内低点),不可执行;可执行买点只能来自系统信号,两者不可混谈;
- 妖股"不可收割"论基于形态结构(一字板无第二买点),属机制论证非回测证明;
- 涨幅榜前5对"核心股"有幸存者偏差——2025年真正的产业核心(新易盛+~380%、中际旭创等)多在榜单第10~30名,它们才是系统的主粮仓;本研究聚焦榜首物种,不代表系统猎物全景;
- 2021~2022 年 bt_universe 覆盖起点与回测起点(2021-02)一致,更早历史未检。
