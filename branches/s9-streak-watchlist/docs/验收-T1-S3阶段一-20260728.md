## 数据审计

### 暖窗

- [x] `warm_daily` 和 `warm_adj_factor` 声明字段非空率均为 100%
- [x] 暖窗最后一天为 2014-12-31
- [x] 生产 `market_daily` 第一天为 2015-01-05
- [x] 两者重叠交易日为 0

因此“与生产行情重叠一致性”为 **N/A**，不是 100%。没有可比较行，不伪造
一致性百分比。暖窗仅参与 2015 年初始 250 日窗口，派生表最早日期为
2015-01-05，没有 2014 年信号或交易。

### `daily.vol`

研究表只含批准的三列 `trade_date/ts_code/vol`。生产 `market_daily` 只有
`trade_date/ts_code/close/pct_chg/high/low/amount/open`，没有 `vol`，
所以数值重叠一致性为 **N/A**。

日期/代码键集合做了全量双向 `EXCEPT`：

```text
生产键数             10,796,305
研究键数             10,796,305
生产有、研究缺       0
研究有、生产缺       0
```

### 申万二级与成分历史

- [x] 行业目录 134 行，全部 `src=SW2021`
- [x] `is_new=Y` 当前记录 5,881 行
- [x] `is_new=N` 历史退出记录 2,004 行
- [x] 2,004 条历史退出记录全部带 `out_date`
- [x] S3 计算没有混入 `pool.industry`

本次不是当前成分反写历史，已具备来源提供的成分变动记录。仍需保留一般性
局限：若 Tushare 上游自身漏报更早的成分变动，历史结果仍可能存在残余
幸存者偏差；T1 不用当前成分静默填补这些未知区间。

### ST

- `stock_st` 实际从 2016-08-09 开始，未覆盖 2016-01-01—2016-08-08。
- 2016 年前使用曾用名区间辅助；`start_date<2016-01-01` 且名称含 ST 的记录
  为 1,539 条。
- 曾用名只能识别有明确名称区间的记录，不能等价于完整日级 ST 名单。

这可能使 2015 年质地底线少剔除一部分当时实际为 ST、但曾用名区间缺失的
股票。该局限已显式保留，不静默当成“非 ST”。

### 年报

- 报告期严格保留 2012—2024 年年报。
- 每个信号日只查询 `f_ann_date <= signal_date` 的记录，再取当时最新一份
  已公开年报；修订记录也只在其实际 `f_ann_date` 到达后可见。
- Tushare `income` 实际返回了 101 条超过请求截止日的 2026 年公告记录。
  入库层现在再次硬过滤 `f_ann_date <= 2025-12-31`，这 101 条已从
  研究库删除，且新增回归测试防止数据源忽略参数时扩大冻结范围。
- 覆盖 5,757 只股票；`revenue` 空 160 个单元，`n_income` 空 312 个单元。
- 声明字段非空率为 99.897919%。必要财务字段缺失时，质地判断返回未知，
  不把未知硬算成通过或不通过。
