{"page_type": "deal"或"position"或"unknown",

- 响应：`{"ok": True, "page_type": ..., "dropped_n": n, "rows": [...]}`，每 row = 识别字段 + 校验结果：

```python
def _ocr_validate_row(t):
    """逐笔交叉校验:三分类+价格合理性。只标注不拦截——拦截是落库时四道闸门的事。"""
    code = str(t["code"]).zfill(6)
    row = storage.pool_get_by_code(code)
    state = (row or {}).get("state")
    open_pos = next((p for p in storage.list_positions("open") if p["code"] == code), None)
    if t["direction"] == "buy" and state == "watchlist":
        cat, note, actionable = "watchlist_buy", "等买点票 ✓", True
    elif t["direction"] == "sell" and (state == "holding" or open_pos):
        cat, note, actionable = "holding_sell", "持有票卖出 ✓", True
    else:
        cat, actionable = "outside", False
        note = "池外票/方向不匹配——按「老账老办法」本期不入系统账,仅展示"
    # 价格合理性:昨收±板幅(30/68开头±19.8%其余±9.8%,同 brief._limit_state 口径)
    price_note = None
    watch = {w.get("code"): w for w in (storage.load_latest() or {}).get("watch") or []}
    prev = (watch.get(code) or {}).get("prev_close")
    if prev and t.get("price"):
        band = 19.8 if code.startswith(("30", "68")) else 9.8
        lo, hi = prev * (1 - band / 100), prev * (1 + band / 100)
        if not (lo <= float(t["price"]) <= hi):
            price_note = f"⚠ 识别价 {t['price']} 超出昨收±板幅区间 {lo:.2f}~{hi:.2f},请核对"
    elif t.get("price"):
        price_note = "无参考价(票不在监控清单),请自行核对"
    return {**t, "code": code, "category": cat, "note": note,
            "actionable": actionable, "price_note": price_note}
```

- 端点主体：images 空/超 4 张拒绝（人话）；单张 b64 长度上限 8MB 拒绝（防误传视频）；调 `reviewer.ocr_trade`——None → `{"ok": False, "error": "截图识别引擎不可用:..."}`；busy → `{"ok": False, "busy": True, "error": "AI 正忙,稍后再试"}`；成功 → 逐笔 `_ocr_validate_row`。
- **不落库**：本端点只识别+校验，落库由前端走 `/api/brief/act`。
