**照抄 `test_rules.py` 的模式**：构造日K DataFrame → 调函数 → 断言 state。关键区别：中线需要 **260+ 根日K**（250日新高窗口），base_df 要够长。

**测试数据构造器**（写到 test_rules_mid.py 顶部）：

```python
import datetime as dt
import pandas as pd
from rules_mid import analyze_mid, check_exit_mid, CONFIG_MID

def base_mid(n=260):
    """构造 n 根日K(默认260根)，前250根在 95~100 区间震荡(平台期)，
    为250日新高突破创造条件。"""
    rows = []
    d = dt.date(2025, 7, 1)
    for i in range(n):
        c = 96.0 + (i % 5) * 0.8  # 95.2~100 区间震荡，高点=100
        rows.append(dict(
            date=d + dt.timedelta(days=i),
            open=c - 0.2, close=c,
            high=c + 0.5, low=c - 0.5, vol=100.0))
    return pd.DataFrame(rows)

def set_bar(df, i, close, vol, open_=None, high=None, low=None):
    """改第i根K线。"""
    df.loc[i, "close"] = close
    df.loc[i, "open"] = open_ if open_ is not None else close - 0.2
    df.loc[i, "high"] = high if high is not None else close + 0.5
    df.loc[i, "low"] = low if low is not None else min(close, df.loc[i, "open"]) - 0.5
    df.loc[i, "vol"] = vol
```
