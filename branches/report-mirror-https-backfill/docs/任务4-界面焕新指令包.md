## 三、v3 设计系统（第八节原文）

### Design tokens（全站执行）

```
背景:     #F5F5F7    (Apple 灰白)
卡片:     #FFFFFF    (纯白)
主文字:   #1D1D1F    (近黑)
次级文字: #6E6E73    (中灰)
发丝线:   #E5E5EA    (浅灰分割线)
主色:     #0A84FF    (Apple 蓝)
提醒:     #B54708    (深橙)

A股约定不变:
  涨/盈:  #E03131    (红)
  跌/亏:  #2F9E44    (绿)

字体: -apple-system, "SF Pro", "PingFang SC"
数字: 等宽 + font-variant-numeric: tabular-nums
```

### 组件规范

- **白卡**：圆角 14px，阴影 `0 1px 3px rgba(0,0,0,.06)`，无粗边框
- **留白**：页面 24px / 卡内 20px / 卡间 16px
- **按钮**：主按钮=蓝底白字圆角10px；次按钮=浅灰背景
- **徽章**：小胶囊（pill）样式，状态用颜色区分
- **禁止**：弹窗轰炸、跑马灯、渐变堆砌、图表装饰化

### 信息架构（顶部极简导航 5 项）

| 页面 | 路由 | 首屏问题 |
|---|---|---|
| **今日** | `/` | "我今天要做什么？"（日报摘要 + 筛选看板合并） |
| **严选池** | `/pool` | "我的票在哪个阶段？" |
| **个股详情** | `/stock/{code}` | "这只票的论点和事件？" |
| **日报** | `/daily` | "今天的完整指令单" |
| **设置** | `/settings` | 参数/Key/用量/历史快照入口 |

**导航 5 项**：今日 / 严选池 / 日报 / 交易台 / 设置（历史快照入口移到设置页或今日页底部）

**设计原则：每屏只回答一个问题。首屏问题永远是"我今天要做什么"。**

### 事项D：今日页合并（index.html 重构）

v3 要求"今日"页 = 日报摘要 + 筛选看板。当前 index.html 只有筛选看板。

**重构 index.html 的信息层级**：

```
┌─────────────────────────────────────┐
│  导航栏                               │
├─────────────────────────────────────┤
│  今日待办 (N件)           ← 新增区域  │
│  [从 /api/daily/latest 拉取待办]     │
│  没有待办 → "今日无操作"大字          │
├─────────────────────────────────────┤
│  筛选看板                             │
│  [原 index.html 的全部内容下移]      │
│  盘中监控 / 明日重点关注 / 新突破 ... │
├─────────────────────────────────────┤
│  历史快照入口                         │
└─────────────────────────────────────┘
```

**实现**：
- 页面加载时先拉 `/api/daily/latest`，有日报 → 顶部显示待办摘要
- 日报不可用 → 不阻塞，下方筛选看板照常显示
- 点待办条目跳转到 `/daily` 或 `/stock/{code}`
