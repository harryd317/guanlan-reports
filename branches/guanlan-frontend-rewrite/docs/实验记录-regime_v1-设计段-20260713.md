- OOS 段:2022-01-01 ~ 今(**冻结参数后只评一次,不迭代**)

### 选择规则(预声明)

1. 先筛:设计段内 翻转≤6次/年 且 持续期中位≥20日 且 KW p<0.05;
2. 过筛者取**翻转次数最低**;并列取持续期中位更长;仍并列取参数居网格中位者
   (边缘参数=过拟合嫌疑);
3. 一旦选定即冻结为 regime_v1,OOS 只评一次,三闸门+三案例全过才交付,
   不过则**项目停在仪表盘**(设计写死),不回头调参再试 OOS。

## 结果(以下按协议执行后填写)

### 第一轮网格:81 组全部不过筛

居中参数诊断(仅看设计段):方向轴翻转 11.9 次/年(同侧退出在均线上方徘徊时反复进出)、
风险合成分中位仅 0.366(新低减新高是 0~0.1 小量纲,直接加权被稀释,上阈 0.70 摸不到)、
KW p=0.386。**特征层无 bug(NaN≈0),是状态机与量纲设计问题。**

### 设计迭代 1(仍只看设计段,OOS 零接触)

1. 方向轴滞回改**对侧退出**:持多直到跌破 -exit_band(横跨带宽的粘性),持空对称;
   TP4C4 钉死新语义,TP4C2/C3 语义不变仍绿;
2. 风险轴三组件(波动率/下跌家数/新低减新高)**全部滚动500日分位化**再加权
   (同一把 0~1 尺;滚动窗=无前视,纪律4不破)。
3. 网格与选择规则不变,重跑。

### 第二轮:KW 修好(全网格 100% p<0.05),翻转仍 6.3~19.9/年,0 过筛

### 设计迭代 2+3:计数滞回二道防线(设计§5.2 明文预留)

合成标签加确认天数 CONFIRM_N(连续 N 日才换判,TP4C5);首轮 N∈{3,5,7} 时
7 是边界且前十全是它 → 按边界延长 {5,7,10,15}(记录在案,非手调)。
第三轮:324 组过筛 125 组,选定(DIR 1.5/0.0,W 0.4/0.3/0.3,RISK 0.65/0.50,N15)。

### 首次 OOS:三闸门✓ + 2018✓ + 2024-09✓,但 2015-06 崩盘✗ → 定位机制缺陷

崩盘窗口 vol_pct500 中位 0.964(风险轴看得见),但宽度分位需 500 日历史,
2015~2016 初整段 NaN → 合成分整行 NaN → Schmitt 维持原判,stressed 永不点火。
**这是"缺失降级"实现与声明不符(声明:缺宽度退化纯波动率;实现:整列全缺才降级),
且暴露它的案例(2015-06)在设计段内**——修正为逐行降级(TP4C6),属机制修 bug
而非看 OOS 调参。诚实记录:OOS 在修正前后各看过一次;缓解:修正方向由设计段
案例+预声明降级规范决定,最终参数仍纯按设计段规则选出。

### 设计迭代 4(逐行降级)后终选与冻结

设计段重跑 93/324 过筛,按预声明规则选定并冻结 **regime_v1**:
`DIR_ENTER=1.5, DIR_EXIT=1.0, W=(0.4,0.3,0.3), RISK_HI/LO=(0.75,0.60), CONFIRM_N=15`
设计段读数:翻转 3.1 次/年 / 持续中位 43 日 / KW p=0.0101;周边参数大面积过筛(高原非尖峰)。

## 最终 OOS 验收(2022-01-01 ~ 2026-07-13,一次性)

- **三闸门 ✓ 全过**:翻转 4.0 次/年(≤6) | 持续中位 34 日(≥20) | KW p<1e-4(<0.05)
- **三案例 ✓ 全过**:2015-06 崩盘(出现 bear_stressed 且窗口 stressed≥60%)/
  2018 阴跌(bear≥50% 且 bull≤15%)/2024-09 逼空(起点非 bull→窗口内转 bull)
- OOS 市况分布:bull_healthy 486 / bear_healthy 449 / neutral_healthy 113 /
  bear_stressed 26 / bull_stressed 20

**结论:regime_v1 通过 P2→P3 闸门,市况标签对未来 20 日收益有显著信息量,
项目可以往背书矩阵(P3)走。** 剩余工程化:regime_history 落库(只追加禁回改)+
每日在线判定 job + 策略中心页(先原型拍板)。
